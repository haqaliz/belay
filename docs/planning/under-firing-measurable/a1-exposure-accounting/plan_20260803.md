## 1. The two data shapes, decided here

Everything downstream follows from these. They are settled in this plan so no phase invents its
own.

### 1.1 On the A1 `Verdict` — an optional key inside `expected`

`Verdict` gains **no field**. Exposure rides the existing free-form `expected` dict, which already
carries `{"rule", "scope", "turn"}` (`invariants.py:254`) and `"cause"` on abstains (`:352`).

```python
expected["exposure"] = {"compared": <int>, "in_scope": <int>}
```

**Absence is the absence of the key.** Not `None`, not `{}`, not `0` — the key is simply not
there. Three cases:

| Situation | `expected["exposure"]` |
|---|---|
| content rule, past the guards | `{"compared": N, "in_scope": M}` |
| content rule, file-budget abstain (`:398`) — `in_scope` known, `compared` never initialised | `{"in_scope": M}`, **no `compared` key** |
| the five early abstains (`:359,365,371,382,388`) and **every `read-only` path** | key absent entirely |

A partial dict is deliberate: `in_scope` at the budget abstain is a real, useful fact (*"512+
files were touched"*), and inventing a `compared` there would be a fabricated zero.

**`compared` means judgement attempts.** It includes deletions, and it increments at `:430`
*before* `_judge_file` at `:431` may return `UNVERIFIED`. That is not smoothed over — it is
stated in the docstring and in the rendered prose.

### 1.2 On `InstanceRecord` — `Optional[dict] = None`, key omitted when unrecorded

```python
exposure: Optional[dict] = None   # {"files_compared": int, "turns_judging": int, "turns_recorded": int}
```

- `files_compared` — sum of `compared` over this instance's turns.
- `turns_judging` — how many turns had `compared >= 1`.
- `turns_recorded` — how many turns carried an exposure fact at all.

**Follow the `detector` pattern, NOT the `not_covered_turns` one.** `not_covered_turns` reads
`raw.get(..., {})` at `ledger.py:274`, which collapses absent into empty — survivable there only
because the report's wording refuses to claim either reading (`report.py:173-177`). **It is not
survivable here**: `files_compared == 0` is a real, material finding (*the rule judged nothing*),
while absent is a format gap, and collapsing them would let every ledger in `runs/` read as *"the
detector was silent because it compared nothing"* — fabricating the exact finding this unit exists
to establish. So: `Optional[…] = None`, `raw.get("exposure")` → `None`, and **the key is omitted
from `to_json`** when `None` (`ledger.py:228-239` is the model).

**Never in `_REQUIRED_INSTANCE_FIELDS`. Never inside `turn_status_counts`** — `total_turns()`
(`ledger.py:165-171`) sums that dict blindly and is the denominator of the FAIL rate, the
UNVERIFIED share and the coverage fractions.

### 1.3 The three states, and the sentence each renders

| State | Condition | Rendering |
|---|---|---|
| **judged** | `exposure is not None and files_compared > 0` | *"judged N file(s) across K turn(s)"* |
| **no opportunity** | `exposure is not None and files_compared == 0` | *"0 file(s) compared — this instance's silence carries no information about the rule"* |
| **unrecorded** | `exposure is None` | *"exposure unrecorded — no exposure fact was recorded here (a ledger written before exposure accounting, an ERRORED instance, no content rule in force, or turns that never replayed); this is NOT a claim that the rule judged nothing"* |

**CORRECTED after the whole-branch review (2026-08-03).** The state NAMES are unchanged; the
last two SENTENCES are. Both originally asserted a CAUSE the code cannot observe, and both
were false in reachable situations — one of them the commonest situation in the real data.

- *"the rule was given nothing to judge"* is false whenever something WAS in scope and simply
  was not comparable: a file absent from the task pre-state is **skipped, not compared**
  (`invariants.py:417-420`), so an agent **adding** a test under `tests/` yields
  `{"compared": 0, "in_scope": 1}` — the rule was given a file and correctly found nothing in
  it to weaken. Adding a test is the commonest agent behaviour in this project's captured
  data. The bounded file-budget abstain lands here too. Only the **count** is true in every
  sub-case, so only the count is stated.
- *"this ledger predates exposure accounting"* is false on a **brand-new** ledger: `exposure is
  None` is also written for every **ERRORED** instance (`runner.py:158-172`), for any run with
  no content rule in force (`--no-default-invariants`, a `read-only`-only policy), and for an
  instance whose turns never replayed. Stage 3 had ERRORED instances and the re-mint will too.
  The possibilities are now named without picking one; the disclaimer half is unchanged.

`belay verify`'s per-turn line additionally spends the `in_scope` count it has in hand —
*"N file(s) in scope, 0 compared"* — because without it the exposure line contradicted the
sub-verdict line printed directly above it (`... (0 file(s) compared, 1 touched)`). The ledger
surfaces do **not** carry `in_scope`; adding it to the ledger schema is a separate follow-up.

### 1.4 The `combine` merge rule — decided

**Per instance, reduce by ANY (union); per capture, sum.** This mirrors the reduction already on
that page: an instance `is_violating` iff **any** capture flagged (`population.py:137-146`), so an
instance is **exposed** iff **any** capture judged ≥1 file, and **unrecorded** iff **no** capture
recorded exposure at all. The per-capture total is the sum, matching `Population.total_turns()`
(`:242-246`), which sums over captures without dedup.

**The rule is printed in the output**, beside the existing `(stage, trace_id)` dedup line — the
same discipline that made the dedup rule visible rather than documented.

## 4. Testing strategy

- **Unit**, per phase, as listed. Naming follows the repo convention — full sentences asserting the
  property (`test_errored_instance_reports_unrecorded_never_zero`), not the code path.
- **Integration:** `tests/test_phase0_e2e.py` must stay green unchanged — it is the strongest
  available check on M0b (no verdict changes value).
- **The M0b guard:** a test asserting that a single-ledger, control-free run's verdicts and rates
  are equal to today's. `ledger-reporting-honesty` states this obligation as *"default behaviour …
  is byte-identical to today"*; this aspect owes the same.
- **No stub-seam evidence.** Phase 5's tests drive the real `verify_turn`.
- **Never loosen an assertion to pass.** If an existing equality assertion is in the way, that is a
  design signal, not a test to weaken.

Full suite after every phase: `uv run pytest`. Expected end state: **1238 + new, 1 skipped,
1 deselected**, zero pre-existing tests modified except by addition.

## 6. Edge cases, and the verdict each produces

| Case | Behaviour | Why |
|---|---|---|
| A1 never ran on a turn (no invariants declared) | `exposure` absent for that turn | nothing judged and nothing claimed |
| A1 ran but the rule is `read-only` | absent | that rule has no exposure concept; a `0` would make the two rules indistinguishable |
| in-scope file present but unreadable | counted in `in_scope`, **not** in `compared`; the verdict is `UNVERIFIED` with its existing named cause | unchanged behaviour; exposure just reports it |
| `compared > 0` **and** the turn is `UNVERIFIED` | both rendered — they are orthogonal | a turn can judge files and still fail to decide |
| in-scope file budget exceeded (512+) | `{"in_scope": M}`, no `compared`; verdict `UNVERIFIED` (`IN_SCOPE_FILE_BUDGET`) | a bounded abstention is the honest answer, and inventing a `compared` would fabricate one |
| ERRORED instance | `exposure is None` → **unrecorded** | *"0 compared"* there would assert the finding this unit exists to establish honestly |
| old ledger re-rendered | `unrecorded`, prominently | `belay phase0 report` is a pure re-render; it must not imply the field was measured |

**There is no silent-pass path in this aspect**, because it computes no verdict. Its failure mode
is not a false PASS but a **false zero**, and every row above exists to close one.

## 7. Agent execution notes

**Checkpoints for human review**
- **After Phase 1** — the nine-path enumeration is the aspect's spine. If a path was miscounted or
  a `read-only` return was edited, everything downstream inherits it.
- **After Phase 2** — the absent-vs-zero boundary. Verify `to_json`'s *bytes*, not the loaded
  object.
- **After Phase 4** — the merge rule is a published-surface decision.

**Likely to need iteration**
- The `abstain()` helper's signature: threading exposure through it without letting the five early
  abstains acquire the ability to emit a zero.
- `render_report`'s fixed order and its docstring contract are asserted by tests; adding a section
  touches both.
- `runner.py`'s ERRORED constructor is **positional** (`:157-167`) — a new defaulted field is
  silently answered for there unless the agent edits it deliberately.

**Ask before proceeding if**
- an existing test must be *modified* rather than added to (this aspect should only add);
- any verdict value changes anywhere (that violates M0b and means the design is wrong);
- `_REQUIRED_INSTANCE_FIELDS` or `turn_status_counts` looks like the natural home for exposure — it
  is not, and the reasons are in §1.2.

**Do not**: widen scope into the corpus (`corpus-recorded-miss` owns it), touch the
`no-assertion-weakening` rule's decisions, or run any measurement over the banked captures
(`miss-measurement` owns that, under the freeze protocol).
