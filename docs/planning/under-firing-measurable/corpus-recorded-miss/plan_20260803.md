## 1. A PROPOSED SCOPE REDUCTION — decide at the gate before Phase 3

The PRD's **M-5** asks for *"an opt-in ingest population on `phase0 run`: explicitly named turn
indices, landing in new `InstanceRecord` buckets"*, with the guarantee that such a case never
enters `flagged_turns` and never moves the violation numerator.

**The dig found that surface already exists, on a different command.** `belay corpus add --turn N`
applies **no FAIL filter** (`cli.py:764-845`) and `add_case` enforces **no precondition on verdict
status** (`add.py:336`). Adding a specific unflagged turn is a single command today, and
`miss-measurement` needs exactly two such turns — both individually named, from two named traces.

**Recommendation: drop the `phase0 run` opt-in from this aspect.**

- The numerator guarantee becomes **structural rather than tested**: `phase0 run` is not involved
  at all, so it cannot move a rate it never computes. That is strictly stronger than adding a
  second ingest population and then proving it inert.
- New `InstanceRecord` buckets would be a **second** optional-field back-compat surface on a
  record that just gained one, for a path with one known caller.
- It is reversible: if a future mint wants bulk miss-ingest, the buckets can be added then, with
  a real caller to shape them.

**What is kept from M-5 regardless:** the help text that asserts a precondition the code does not
have is corrected, and the manual path is documented so it stops being a secret.

**If you reject this reduction**, Phase 3 grows a sixth task and the plan below is otherwise
unchanged. Flagging it rather than deciding it, because it narrows a stated must-have.

## 2. The two data shapes, decided here

### 2.1 The declaration on a case — schema v3

`CASE_SCHEMA_VERSION` (`case.py:80`) goes **2 → 3**. `Case` gains:

```python
recorded_miss: Optional[dict] = None   # {"note": <non-empty str>}
```

- **Presence is the declaration.** Absent ⇒ undeclared ⇒ a normal case, byte-for-byte today's
  behaviour. This copies `task_prestate`'s rule verbatim — *"the bundle is DECLARED in
  `case.json`, never inferred… presence of a directory on disk is not the declaration"* — and
  `_to_payload` (`case.py:233-249`) already omits unset optionals rather than writing `null`.
- **A `note` is REQUIRED and must be non-empty.** This mirrors `curate.py:74-79`, where a
  `true-positive` label requires a `root_cause`: a human asserting *"the engine missed something
  here"* must say what. A declaration with no note is a `ValueError`.
- **Malformed ⇒ named `ValueError`**, fail-closed like every other field in `case.py`.
- **Never added to `_REQUIRED_FIELDS`** — *"a required new field would reject every case already
  sitting in `corpus/local/`"*.
- **The engine never sets it.** No code path from a verdict, a status, or a label to this field.
  This is the D3 boundary of `add.py:34-42` applied to a second field, and it gets a structural
  test, not a comment.

**Why an object and not a boolean:** a bare `true` records that someone made a claim and nothing
about the claim. The note is what makes the case auditable by the next reader, which is the whole
premise of the corpus.

**Why the version bump:** a v3 case read by older code would be silently misclassified as a
normal case — MATCH-certifying blindness, the exact defect this aspect removes. The bump makes
that visible. Note the existing precedent: `schema_version` is *absent ⇒ `_UNVERSIONED = 1`*
(`case.py:83-87`), deliberately not the current version.

### 2.2 Two new outcomes on `corpus run`

`run.py:74-76` has `MATCH` / `REGRESSION` / `SKIP`. Add two, **reachable only for a declared
recorded-miss case**:

| Outcome | When | Exit |
|---|---|---|
| `STILL_MISSED` | recomputed set **equals** `expected` — the engine still does not catch it | 0 |
| `MISS_CLOSED` | the **only** divergences are the reduced status and the A1 `invariant` sub-verdict both moving `PASS → FAIL` | 0 |
| `REGRESSION` | **any other** divergence, on a declared case or not | 1 |

- `STILL_MISSED` exists because `MATCH` on a recorded miss would certify blindness as a pass. It
  is not a failure — it is the known state — but it must not be called agreement.
- `MISS_CLOSED` is the criterion that stops **CI going red for a fix**.
- The escape is deliberately **narrow**: exactly one transition is exempted. Anything else —
  an A2 divergence, a move to `UNVERIFIED` without a `_SKIP_CAUSES` cause, a `WARN` — is still a
  `REGRESSION`. This is criterion 6 in the spec and it is what keeps the declaration from
  becoming a blanket exemption.
- **`classify_case` must not read `human_label`.** It reads the declaration and the verdicts.
  Coupling classification to the labels `corpus score` scores independently would corrupt both.
- **`_SKIP_CAUSES` is NOT widened** (`run.py:97-102`, and the doctrine at `run.py:31-35`): a SKIP
  means *"this box could not evaluate the case"*; a recorded miss is identical on every box.
- `CorpusRun.has_regression` (`run.py:~150`) counts **only** `REGRESSION` — unchanged, and that
  is the exit contract.

## 4. Testing strategy

- Every phase's tests go in `tests/test_corpus_recorded_miss.py` (repo convention: an aspect gets
  its own file), except the help-text test, which belongs beside the CLI tests.
- **Test naming:** full sentences asserting the property, per repo convention.
- **The regression risk to guard:** `classify_case` is compared by **exact dict equality**
  (`run.py:~225`). The two new outcomes must not weaken that for undeclared cases — assert an
  undeclared case's classification is bit-for-bit what it was.
- **No stub seams for load-bearing behaviour.** `run_case` drives real re-verification; the
  classification tests are legitimately pure (`classify_case` is a pure function), but at least
  one end-to-end `corpus run` test must exercise a declared case through the real path.
- Full suite after every phase. Expected end state: **1286 + new**, 1 skipped, 1 deselected, zero
  pre-existing tests modified.

## 5. Environment & determinism

No env vars, no network, no API key, no model call. No clock read inside `add_case` (`captured_at`
stays injected). Cases remain **machine-bound through `server_command`** (absolute paths into
`eval/servers/`) and off darwin every case is an up-front SKIP — inherited, not worsened.

## 6. Edge cases, and what each produces

| Case | Behaviour | Why |
|---|---|---|
| v2 case, no declaration | classifies exactly as today | back-compat is the whole point of presence-is-declaration |
| declared case, recompute UNVERIFIED with a `_SKIP_CAUSES` cause | `SKIP`, as today | an environment gap outranks everything; the case was not evaluated here |
| declared case, recompute UNVERIFIED **without** such a cause | `REGRESSION` | engine/case corruption is a real divergence — `run.py:31-35` forbids hiding it |
| declared case, recompute now `WARN` | `REGRESSION` | only `PASS → FAIL` is the exempted transition |
| declared case, A2 sub-verdict also moved | `REGRESSION` | the escape covers the A1 invariant transition only |
| declaration present, `human_label` still `pending` | classification unaffected; `corpus score` still excludes it | classification and scoring stay independent by design |
| declaration on a case whose `expected` is already `FAIL` | `ValueError` at load — a "miss" that was caught is a contradiction | fail-closed beats a case that means nothing |

## 7. Agent execution notes

**Checkpoints:** after Phase 1 (the schema boundary — assert serialized bytes, not the loaded
object) and after Phase 2 (the exit contract; verify `has_regression` still counts only
`REGRESSION`).

**Likely to need iteration:** the exact transition-matching rule in `classify_case`. It must be
narrow enough that criterion 6 holds and general enough that a real fix does not trip it. Write
the four spine tests first and let them shape it.

**Ask before proceeding if:** an existing test must be modified rather than added to; any
undeclared case's classification changes; `_SKIP_CAUSES` looks like the natural home for this
(it is not — `run.py:31-35` says why); or the declaration starts being inferable from a verdict
or a label.

**Do not:** touch the `no-assertion-weakening` rule, run any measurement over the banked captures
(`miss-measurement` owns that, under the freeze protocol), or add an `--overwrite`/`--force` to
`corpus add` — *"the engine must not have a supported path to overwrite a human adjudication."*
