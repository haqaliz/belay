Adjudication is **human judgment**, and this repo keeps that grade strictly separate from execution
(`PHASE0_RESULTS.md`: *"Two evidence grades, never merge them"*). Three options:

- **(a) The owner decides**, from a prepared packet (pre-state, post-state, the exact assertion
  diff, upstream's own fix). Highest grade; the packet is preparable either way.
- **(b) I adjudicate and the owner confirms**, with the reasoning written out beside the verdict so
  it can be checked rather than trusted. This is what produced the existing hand-adjudications on
  the record.
- **(c) Defer** — publish exposure only, and leave both turns `pending` for a later unit.

**Phases 1-4 and 6 are unaffected**; only Phase 5 depends on this. **Prepare the packet regardless**
— it is the same artifact under (a) and (b), and it is what makes (c) resumable.

## 2. Phases

### Phase 0 — Time the smallest stage, WITHOUT observing its result

`M-10a` requires the budget be known rather than discovered: v0.11.0's wall-clock was never
recorded, and the protocol permits one run.

```
/usr/bin/time -p uv run belay phase0 run "$MINT/s1p/batch" \
    --ledger /dev/null --no-ingest --server node "$SERVER" '{workspace}' > /dev/null 2>&1
```

Three properties that keep this from being a covert first run:
- **`--no-ingest`** — the corpus is never written, so nothing is banked from an unfrozen invocation.
- **stdout to `/dev/null`** — the timing is observed, **the verdicts are not**. The freeze protocol
  exists to stop iterating against the data until it says something; a probe that cannot say
  anything cannot be iterated against.
- **It is DECLARED in the write-up** as a timing probe, with its command, exactly as clause 3
  requires of anything that is not the one run.

Extrapolate: s1p is 11 turns of 392, so multiply by ~36 for a first-order budget. **If the estimate
exceeds ~2 hours, stop and re-plan** — a one-shot run that cannot be supervised to completion is a
protocol hazard, not a schedule problem.

**Commit:** `miss-measurement: the timing probe, declared, before the run it budgets`
