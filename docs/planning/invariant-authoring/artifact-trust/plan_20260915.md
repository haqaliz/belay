# Plan: `artifact-trust` — the authored artifact schema and verify-side trust

**Date:** 2026-09-15
**Aspect spec:** `docs/planning/invariant-authoring/artifact-trust/spec.md`
**PRD:** `docs/planning/invariant-authoring/prd.md` (M4, M5, M6)
**Land order:** **first** — this aspect defines the interface the other three build against.

## Decisions carried into this plan (flag any disagreement before Phase 1)

- **D-1 — the new producer is `parse_authored_invariants(payload)`, public, taking
  only the parsed JSON payload.** `load_invariants(path)` keeps its single call
  site and single parameter (`path`) and dispatches on shape internally: a JSON
  **list** takes the existing byte-identical path; a JSON **object** is handed to
  `parse_authored_invariants`. This satisfies M6 literally (the provenance guard
  admits a fourth producer by name) without duplicating the loader across the four
  surfaces. `parse_authored_invariants` takes no records, no path, no trace.
- **D-2 — trust rides on the `Invariant` as `untrusted_cause: str | None = None`.**
  Existing constructors are keyword-based and equality-compatible; the field is
  additive. `evaluate_invariant` short-circuits untrusted invariants to UNVERIFIED
  immediately after `expected` is built (`invariants.py:402`), mirroring the
  egress abstain shape (`invariants.py:415-425`).
- **D-3 — the canonical policy digest covers the normalized policy set plus the
  task and control sha256s; rationale text is excluded.** So a rationale edit does
  not invalidate, a scope/rule edit does.
- **D-4 — the authored artifact records `author.program` (argv[0]) and an optional
  self-reported model id, never the full command line** — a committed artifact must
  not leak a token that rode in the operator's command.

## Phase 1 — RED tests (`tests/test_authored_invariants.py`)

Write these failing tests first; no production code before them.

1. `parse_authored_invariants` with a well-formed calibrated artifact → invariants
   with `untrusted_cause is None`, `scope`/`rule` correct, and enforcement identical
   to the same declarations loaded as an operator list (compare `evaluate_invariant`
   verdicts on a synthetic delta).
2. Missing `calibration` block, `control.calibrated` not `true`, or a malformed
   block → every invariant carries `untrusted_cause == AUTHORED_INVARIANT_UNCALIBRATED`.
3. Digest mismatch (edit a scope after calibration) → `AUTHORED_INVARIANT_ALTERED`.
4. Rationale-only change → still trusted (`untrusted_cause is None`).
5. Unknown rule inside an artifact → `ValueError`; unknown `schema` string →
   `ValueError`; a JSON object that is neither shape → `ValueError`.
6. `load_invariants` shape dispatch: a plain operator list is byte-unchanged
   (existing tests keep passing unmodified); an authored object dispatches.
7. `evaluate_invariant` on an untrusted invariant → UNVERIFIED with the cause in
   `expected["cause"]`, on every turn, for every status the underlying evaluation
   could have produced (parameterize over a delta that would FAIL a trusted rule) —
   never PASS, never FAIL.
8. `canonical_policy_digest` determinism: same policy set → same digest; entry order
   irrelevant; rationale excluded; task/control hashes included.
9. **Amend the provenance guard** (`tests/test_invariants.py:98-108`): the producer
   set becomes `{load_invariants, default_invariants, resolve_library_entry,
   parse_authored_invariants}`, and a new pin asserts
   `parse_authored_invariants` takes exactly `["payload"]` — no path, no records.

## Phase 2 — GREEN (`src/belay/verify/invariants.py`)

1. Add the constants near the existing cause vocabulary (`:135-147`):
   - `AUTHORED_INVARIANT_UNCALIBRATED = "authored-invariant-uncalibrated"`
   - `AUTHORED_INVARIANT_ALTERED = "authored-invariant-altered"`
   - `AUTHORED_SCHEMA = "belay-authored-invariants/1"`
   Export all in `__all__`.
2. Add `untrusted_cause: str | None = None` to `Invariant` (`:158-168`) with a
   docstring stating the honesty rule: an untrusted authored invariant is UNVERIFIED
   by construction, never enforced.
3. Add the short-circuit in `evaluate_invariant` after `expected` is built
   (`:402`), mirroring the egress message shape; it fires before the content-rule
   dispatch and before the delta checks.
4. Add `canonical_policy_digest(*, invariants: Sequence[Invariant], task_sha256:
   str, control_sha256: str) -> str`: canonical JSON (`sort_keys=True`,
   `separators=(",", ":")`) over `[{"rule", "scope"}]` sorted by `(rule, scope)`
   with scopes `os.fsdecode`d, plus the two hashes; sha256 hex.
5. Add `parse_authored_invariants(payload: Mapping[str, Any]) -> list[Invariant]`:
   schema check, per-entry validation via the existing `_parse_invariant` rules
   (unknown rule → `ValueError`), digest recompute, and `untrusted_cause` set on
   every invariant when calibration is missing/failed or the digest mismatches.
6. Extend `load_invariants` (`:190-226`) with the shape dispatch: `list` →
   unchanged; `dict` → `parse_authored_invariants`; anything else → the existing
   `ValueError` contract.

## Edge cases

- A payload with `invariants: []` → valid but empty (the caller decides; infer never
  emits it, and `verify` with an empty policy file is the existing empty-policy
  behavior — no new hazard).
- A digest computed over a policy set with duplicate entries → duplicates are
  normalized before hashing; enforcement keeps them (harmless, deterministic).
- `control.calibrated` present but `true` as a string → fail-closed (not `is True`)
  → uncalibrated, never trusted.
- Unicode scopes → `os.fsencode`/`os.fsdecode` round-trip, same as the operator
  loader.
