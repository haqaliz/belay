# Plan: `reference-author` — the `claude -p` reference author and the live proof

**Date:** 2026-09-15
**Aspect spec:** `docs/planning/invariant-authoring/reference-author/spec.md`
**PRD:** `docs/planning/invariant-authoring/prd.md` (M7)
**Land order:** third (after `authoring-protocol`).

## Decisions carried into this plan

- **D-9 — the reference author lives in the wheel at
  `src/belay/authoring/reference_author.py`, runnable as
  `python -m belay.authoring.reference_author --model <full-id>`.** A self-hoster
  installing from PyPI cannot reach `eval/` (explicitly "NOT a product surface",
  `eval/README.md`), so the convenience ships where the user can run it. It is
  dark by default: nothing invokes it unless the operator points `--author` at it.
- **D-10 — the argv and env guarantees are copied from the proven client, not
  imported.** `eval/minting_driver/clients/claude_cli_client.py` is the precedent
  (`_build_command` `:422-447`, `_build_env` `:709-723`, `SCRUBBED_ENV_VARS`
  `:117-121`); the reference author reimplements the same shape stdlib-only and
  never imports `eval/`.
- **D-11 — the live run is an owner checkpoint, not an autonomous step.** It spends
  the owner's subscription. The implementer writes the `manual`-marked test and the
  recording template; the owner runs it and its verbatim output is committed as
  evidence. The unit is complete without it only if the owner declines — and then
  the record says so.

## Phase 1 — RED tests (`tests/test_reference_author.py`), all offline

1. **Argv.** With an injected `runner=` (a fake `subprocess.run`), the constructed
   argv contains `-p`, `--output-format json`, `--model <full-id>`,
   `--tools ""` **and** `--strict-mcp-config` (asserted separately),
   `--safe-mode`, `--no-session-persistence`. A model alias (`opus`, `sonnet`) is
   rejected with a named error (full ids only — the D-2 discipline,
   `subscription-model-client/prd.md:350`).
2. **Env scrub by absence.** The child env is a copy with
   `ANTHROPIC_API_KEY` / `ANTHROPIC_AUTH_TOKEN` / `ANTHROPIC_BASE_URL` removed by
   `pop` — a variable never set stays absent, never `""`; `os.environ` is
   unmutated; no key is read or passed. Asserted on the constructed **env**, not
   only the argv.
3. **Protocol round trip.** Given the protocol JSON on stdin and a fake runner
   returning a canned `claude -p --output-format json` envelope whose `result`
   text is the protocol JSON, the author emits protocol JSON on stdout that
   `parse_author_response` accepts. The envelope parsing follows the precedent
   (`claude_cli_client.py:516-580`: parse the envelope, then the inner JSON).
4. **Failure modes.** Non-zero child exit, unparseable envelope, or an inner text
   that is not the protocol JSON → non-zero exit with a named error on stderr, no
   partial stdout.
5. **Offline by construction.** No test spawns `claude`; the live smoke is
   `manual`-marked and never collected in CI (`pytest.ini`/markers as the repo
   already defines `manual`).
6. **Zero new dependencies / SDK-absent import contract.** The module imports
   stdlib only; the repo's import-contract test pattern
   (`tests/test_minting_driver_clients_import.py`) covers the new module.

## Phase 2 — GREEN: `src/belay/authoring/reference_author.py`

1. `_build_command(binary, model, prompt, system_prompt) -> list[str]` — the argv
   above; model id validated (no alias, non-empty).
2. `_build_env() -> dict[str, str]` — `os.environ.copy()` then `pop` the three
   vars; never write `""`.
3. `_build_prompt(payload: Mapping) -> str` — the system prompt (author
   instructions: propose invariants for the task, from the vocabulary, JSON only)
   + the protocol JSON.
4. `main(argv=None) -> int` — read stdin, run the child through the injectable
   `runner=`, parse the envelope's `result`, extract the single JSON object
   (fail-closed), print protocol JSON to stdout, exit 0; every failure path exits
   non-zero with a named message on stderr.
5. `if __name__ == "__main__": raise SystemExit(main())`.

## Phase 3 — the live proof (owner checkpoint)

1. `tests/test_reference_author_live.py` — `@pytest.mark.manual`, runs
   `infer` with the reference author on the launch demo's task spec
   (`docs/planning/launch-demo/` — read the committed capture's task description),
   calibrated against the committed launch capture
   (`demo/capture/trace-20260827T001428Z-e23f999d.jsonl` + its manifests), then
   verifies the capture with the emitted artifact and asserts **no FAIL**.
2. **Owner checkpoint:** ask before running; it spends the subscription. Record
   the verbatim output in
   `docs/planning/invariant-authoring/reference-author/live-run.md` with the
   exact command, the model id, the wall clock, and the outcome.
3. Read the result as **"the path works at n=1"** — never a quality claim about
   the model's invariants. If the model produces nothing calibratable, that is a
   recorded result (PRD R-g), not a failure to hide.

## Edge cases

- The child prints a JSON envelope whose `result` is prose containing a JSON block
  → extract only if unambiguous; otherwise fail-closed (never guess a policy).
- A model reply with extra candidates the vocabulary cannot ground → each is
  dropped by validation with its cause; the survivors proceed.
- Timeout → kill the child, non-zero exit, no output.
- `claude` absent from PATH → named error, exit non-zero (infer reports
  `AUTHOR_FAILED`).
