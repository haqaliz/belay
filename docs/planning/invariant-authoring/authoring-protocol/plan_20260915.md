# Plan: `authoring-protocol` — the infer subcommand, the author seam, calibration

**Date:** 2026-09-15
**Aspect spec:** `docs/planning/invariant-authoring/authoring-protocol/spec.md`
**PRD:** `docs/planning/invariant-authoring/prd.md` (M1, M2, M3)
**Land order:** second (after `artifact-trust` — it consumes the schema/digest helper).

## Decisions carried into this plan

- **D-5 — calibration replays the control through `verify_turn`, the same function
  `belay verify` calls (`cli.py:843`), with ONLY the candidate invariants (never the
  defaults).** One pass for the whole candidate set; FAILs are attributed per
  invariant via `Verdict.expected["rule"]` + `["scope"]` (`invariants.py:402`).
- **D-6 — `CONTROL_UNREPLAYABLE` fires when no control turn yields a decided A2
  (result-equivalence) sub-verdict** — the control never actually re-executed, so
  calibration would be vacuous. Every candidate is rejected; exit 2.
- **D-7 — the author protocol input never contains the control trace's records or
  path** (task text + bounded repo inventory + rule vocabulary + library entries
  only). Calibration is independent of the author. Honest limit: an operator's own
  author command runs locally and can read anything; the engine's contract is what
  *it* sends, and the reference author only reads stdin.
- **D-8 — `--author` is a required flag; no env var in the first slice.** The
  `BELAY_CLAIM_AUTHOR` env pattern is A3's; this unit is dark by default and
  explicit. Unset → argparse error (exit 2), plus a named check.

## Phase 1 — RED tests: the protocol (`tests/test_invariant_authoring_protocol.py`)

1. `build_author_input(...)` produces canonical JSON (`sort_keys=True`): task text,
   optional `repo` (`root` + bounded sorted file list), the rule vocabulary
   (`rule`, `grounding`, `semantics` for every `_KNOWN_RULES` member plus the
   library's `network-egress` documented as ungrounded), and the library entries
   (`name`, `description`).
2. The input contains **no control records, no trace path, no manifests** (D-7) —
   asserted on the serialized bytes.
3. `parse_author_response(stdout)`:
   - valid `{"candidates": [{"scope","rule","rationale"}]}` → candidates;
   - `{"error": "..."}` → `None` with cause `AUTHOR_FAILED`;
   - malformed JSON / non-object / missing `candidates` / non-list → cause
     `AUTHOR_OUTPUT_UNPARSEABLE`;
   - a candidate with an unknown rule → dropped with `UNKNOWN_RULE` (others kept);
   - non-str scope/rule, empty scope, non-str rationale → dropped with a named
     cause (never a crash).
4. Candidate normalization: scope → `os.fsencode`, deterministic ordering by
   `(rule, scope)`.

## Phase 3 — RED tests: infer orchestration (`tests/test_invariant_infer.py`)

Use the fake-author seam (`runner=`) plus the existing trace/snapshot fixture
helpers (`tests/test_verify_cli_invariants.py:42-108`, `tests/conftest.py`).

1. **Happy path.** Fake author proposes a known-good invariant; `infer` calibrates
   against a clean control and writes the artifact; `belay verify --invariants
   <artifact>` FAILs the corrupt fixture **at the exact turn** naming the rule and
   diff, and PASSes/abstains the clean control.
2. **Author failure modes** (non-zero exit, timeout, unparseable stdout, missing
   key) → exit 2 with the named cause, **no artifact at `--out`** (assert the path
   does not exist), no partial file.
3. **Unknown rule** → dropped with `UNKNOWN_RULE`; if no candidate survives → exit
   2, no artifact.
4. **Calibration rejects over-fire.** A fake author proposes a candidate that FAILs
   the control → rejected with `CALIBRATION_FAILED`; no survivor → exit 2.
5. **Calibration is the shipped composition.** Monkeypatch
   `belay.verify.turn.verify_turn` with a spy: it is called once per control turn,
   with `invariants` = the candidates only, and `infer` performs no replay of its
   own (no second evaluator).
6. **Vacuous calibration.** A control that cannot replay (server that does not
   offer the tool / unrestorable pre-state) → `CONTROL_UNREPLAYABLE`, exit 2, no
   artifact.
7. **Hostile task spec.** A task spec inducing an over-broad candidate is rejected
   by calibration; no FAIL is ever emitted from it.
8. **Determinism.** Fixed fake author + fixed control + fixed task → byte-identical
   artifact across two runs.
9. **Dark by default.** Missing `--author` → exit 2 named, no artifact.
10. **`--json` surface** reports candidates, rejections + causes, calibration
    result, artifact path.

## Phase 4 — GREEN: `src/belay/authoring/infer.py` + CLI wiring

1. `run_infer(...)`: read task, build input, run author, parse/validate, calibrate
   (one `verify_turn` pass over the control, D-5/D-6), emit the artifact atomically
   (`os.replace`), return a structured result.
2. CLI: new top-level `invariant` group with `infer` (registered beside
   `invariant-library`, `cli.py:3858`). Flags: `--task` (required), `--repo`,
   `--author` (required), `--control` (required), `--manifest-dir` (default
   `<control-stem>.manifests` sibling **only when it exists**), `--server`
   (REMAINDER, required), `--timeout`, `--replays`, `--out` (required), `--json`.
   Fail-closed exit 2 with the named cause on every path; no artifact on failure.
3. **Flag parity** (`tests/test_cli_flag_parity.py`): add `"invariant infer"` to
   `REPLAY_BEARING` and to the `EXPECTED` rows for `--server`, `--replays`,
   `--timeout`, `--manifest-dir`, `--json`; the two table tests must pass.

## Edge cases

- Control with zero tool calls → `CONTROL_UNREPLAYABLE` (nothing to calibrate).
- `--turn`-style narrowing is **not** offered on infer; the control is whole-trace
  by construction.
- A candidate set with duplicate entries → deduplicated before calibration,
  deterministically.
- `--repo` inventory cap (e.g. 5000 entries, sorted relative paths) — a huge repo
  must not blow the author prompt or the artifact.
- The artifact is written only after calibration succeeds; any failure leaves the
  `--out` path untouched.
