## Decisions carried into this plan

- **D-12 — the fixture vocabulary is `no-assertion-weakening` on a `tests/` scope
  plus one delta rule (`no-create`).** The first is the shape A1's history is
  built on (the 7 negative fixtures and `pytest-5227`); the second proves the
  delta path. Both are already `_KNOWN_RULES` members.
- **D-13 — reuse, do not rebuild.** The fixture helpers
  (`tests/test_invariant_library_e2e.py:236-316`: `_snapshot`, `_tools_list`,
  `_call`, `_reply`, `_trace`, `_entry_trace`) and the cheat servers
  (`tests/fixtures/create_server.py`, `weakening_editor_server.py`) are the
  infrastructure. New code is the authored-artifact layer on top, not a second
  fixture rig.
- **D-14 — the author is never re-run on recompute.** Cases store the invariant
  declarations (schema v5 unchanged); `corpus run` rebuilds them from the stored
  dicts (`run.py:770-781`). The regression simulation edits the STORED policy,
  not the author.

## Phase 1 — RED tests (`tests/test_invariant_authoring_e2e.py`, darwin-gated)

`pytestmark = pytest.mark.skipif(sys.platform != "darwin", reason="replay-reinvokes-seatbelt: ...")`
— the same gate and reason as `test_invariant_library_e2e.py:67-70`.

1. **Fire at the exact turn.** For `no-assertion-weakening` and `no-create`:
   a fake author proposes the invariant; `infer` calibrates against a clean
   control fixture and emits the artifact; `belay verify --invariants <artifact>`
   FAILs the corrupt fixture **at the exact turn**, naming the invariant and the
   diff, while A2 independently returns PASS on that same turn (the C5 contract).
2. **No over-fire.** The same artifact verified against the clean control yields
   no FAIL (PASS or UNVERIFIED).
3. **Banked and MATCH.** Each corrupt fixture banks via real `add_case`;
   `belay corpus run` reports **MATCH** per case, 0 REGRESSION, 0 SKIP.
4. **Regression simulation.** Emptying the stored invariants flips the case to
   **REGRESSION** (the pattern `test_invariant_library_e2e.py:442-463` uses).
5. **The author is never re-run on recompute.** Recompute with no author
   configured (and with a fake author command that would fail if invoked) still
   MATCHes — the stored policy is what is enforced.
6. **Tamper degrades end-to-end.** Editing a scope in the emitted artifact →
   `verify` yields UNVERIFIED with `AUTHORED_INVARIANT_ALTERED` on the corrupt
   fixture, never FAIL; the corrupt fixture with the untampered artifact FAILs.
7. **Deterministic and offline.** No network, no model; only the fake-author seam.

## Phase 2 — GREEN: fixtures and wiring

1. A small fake-author helper for this test module (the `runner=` seam) that
   returns the two candidate sets deterministically.
2. Reuse the existing cheat servers and trace helpers; build the clean control and
   corrupt fixtures per rule.
3. No production code is expected beyond what the other three aspects shipped; if
   a gap appears, fix it in the owning aspect, not here.

## Edge cases

- The clean control must be genuinely clean for the candidate rule — choose the
  control per rule (the launch capture is not clean for a `source-read-only`
  candidate; that is the calibration working as designed, not a fixture bug).
- The corrupt fixture must violate the rule **at one turn only**, so the exact-turn
  assertion is meaningful.
- Seatbelt-gated: the darwin skip reason must name the cause, never a bare skip.
