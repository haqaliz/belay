## 5. Edge cases / verdict

No verdict path changes. `claim` and `claim_silence` are mutually exclusive by
construction (assert it in the round-trip test). A ledger hand-edited to carry both →
the loader accepts, the report renders `claim` (the verdict wins; silence is a
non-verdict) — pinned, not guessed. **Ask before proceeding** if the refutation module
needs any edit beyond AC 4 + its docstring paragraph.
