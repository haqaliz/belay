# author-abstention — implementation plan (2026-09-25)

Spec: `spec.md`. Strict TDD: every phase starts with a failing test, run and observed RED,
before production code. Suite green at every commit. No network, no model, no clock
dependence (timeouts use a `sleep` stub with a 0.2 s injected timeout — the only
wall-clock-sensitive test; the stub sleeps 5 s so the margin is 25×).

## 1. Overview

Record *why* an author abstained, at the seam where the reason exists, without changing
any return value or status. Files: `src/belay/verify/claims.py`,
`src/belay/verify/author.py`; tests `tests/test_verify_author_abstention.py` (new),
`tests/test_verify_claims_subcause.py` (new), `tests/test_claim_vocabulary_guard.py` (new).

## 2. Phases

### Phase 1 — vocabulary + `Abstention` type
- **RED:** `tests/test_claim_vocabulary_guard.py` — imports `SUB_CAUSES`, `Abstention`,
  the 8 `SUB_CAUSE_*` names from `belay.verify.claims`; asserts `SUB_CAUSES` equals the
  pinned literal set of 8 strings; asserts the claim `CAUSE_*` exports in `__all__`
  equal the pinned set of 5; `Abstention` is frozen with fields `(sub_cause, detail)`
  and rejects a sub-cause outside `SUB_CAUSES` (`ValueError` in `__post_init__`).
- **GREEN:** add to `claims.py` next to `CAUSE_*` (after line ~89): the 8 constants,
  `SUB_CAUSES = frozenset({...})`, `@dataclass(frozen=True) class Abstention`, and a
  `_one_line(text: str, limit: int = 200) -> str` helper (collapse `\s+` runs incl.
  newlines to one space, drop non-printables, strip, cut to `limit-1` + `…`). Export in
  `__all__` (sorted position).
- **Validation:** `uv run pytest tests/test_claim_vocabulary_guard.py tests/test_verify_claims.py -q`
- **Commit:** `feat(author-abstention): the closed sub-cause vocabulary for NO_CHECK_AUTHOR`

### Phase 2 — `SubprocessAuthor.last_abstention`
- **RED:** `tests/test_verify_author_abstention.py` — spec AC 1–4, 6. Stubs are
  `[sys.executable, "-c", "<script>"]` (no fixture files needed): e.g. exit-1 stub
  `import sys; sys.stderr.write("x\nAuthorTimeoutError: boom\n"); sys.exit(1)`; over-cap
  stub writes `"a" * (1024*1024 + 10)`; the edge stub writes `'{"source":"s","argv":["true"]}'
  + " " * (1024*1024)`; not-launched uses `("/nonexistent/belay-author",)`.
  Each asserts `author_check(...) is None` **and** `last_abstention` equality.
- **GREEN (`author.py`):**
  - `__init__`: `self.last_abstention: Optional[Abstention] = None`.
  - `author_check`: set `self.last_abstention = None` first. Split the `try`:
    `except subprocess.TimeoutExpired:` → `AUTHOR_TIMED_OUT`, detail
    `f"no reply within {self.timeout:g}s"`; `except OSError as exc:` →
    `AUTHOR_NOT_LAUNCHED`, detail `type(exc).__name__`; `except Exception as exc:` →
    same sub-cause (keep the `noqa` comment).
  - non-zero exit: detail `f"exit {rc}"` + `f": {_one_line(last non-empty stderr line)}"`
    when one exists → `AUTHOR_EXITED_NONZERO`.
  - parse: change `_parse_check` to `_parse_check_reason(stdout) -> tuple[Optional[Check],
    Optional[tuple[str, str]]]` returning `(check, None)` or `(None, (sub_cause, detail))`
    with details `invalid JSON` / `not an object` / `bad source` / `bad argv`, and for
    `{"error": e}` → `(AUTHOR_REPORTED_ERROR, _one_line(str(e)))`. Keep `_parse_check`
    as a thin wrapper returning `[0]` (other callers/tests use it — grep first).
  - over-cap: `raw = proc.stdout`; parse `raw[:_MAX_OUTPUT]`; if the parse fails **and**
    `len(raw) > _MAX_OUTPUT` → `AUTHOR_OUTPUT_OVER_CAP`, detail `f"stdout exceeded
    {_MAX_OUTPUT} bytes"`; else the parse reason.
  - Every `return None` path sets `last_abstention` immediately before returning.
- **Validation:** new file + `uv run pytest tests/test_verify_author.py -q` **unmodified**
  (spec AC 2) — confirm with `git diff --stat tests/test_verify_author.py` = empty.
- **Commit:** `feat(author-abstention): SubprocessAuthor records why it abstained`

- **GREEN (`claims.py`):**
  - `RecordingAuthor`: `last_abstention` property → `getattr(self._inner,
    "last_abstention", None)` (read live, never cached — so it reflects the latest call).
  - `_unverified(...)`: new keyword `abstention: Optional[Abstention] = None`; when set,

    ({sub})"` when detail empty.
  - raise branch (`:340`): `abstention=Abstention(AUTHOR_RAISED, type(exc).__name__)`.
  - `None` branch (`:347`): `abstention = getattr(author, "last_abstention", None) or
    Abstention(AUTHOR_DECLINED, "")`.
  - Update the module docstring table's `NO_CHECK_AUTHOR` row to name the sub-cause.
- **Validation:** `uv run pytest tests/test_verify_claims*.py tests/test_claim_vocabulary_guard.py tests/test_refutation_no_claim_axis.py -q`, then full `uv run pytest -q`.
- **Commit:** `feat(author-abstention): NO_CHECK_AUTHOR carries its sub-cause`

## 3. Build order

1. `claims.py` (constants, `Abstention`, `_one_line`) → 2. `author.py` (imports
`Abstention` + constants from `claims` — the existing import direction, no cycle) →
3. `claims.py` evaluator + `RecordingAuthor`.

## 4. Testing

Unit only; no sandbox needed (the evaluator's runner/replay seams are stubbed as in
`test_verify_claims.py`). Predicted +20 to +28 tests.

## 5. Edge cases / verdict

Every path stays UNVERIFIED `NO_CHECK_AUTHOR` — the sub-cause refines the reason, never
the status. An author object with a `last_abstention` of the wrong type → treated as
absent (`isinstance(..., Abstention)` check) → `AUTHOR_DECLINED`; never a crash.
**Ask before proceeding** if any existing test asserts the exact `NO_CHECK_AUTHOR`
message text (the dig found none).
