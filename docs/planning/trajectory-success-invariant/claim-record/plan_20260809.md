## Implementation phases

### Phase 1 — The `append_claim_record` helper

- **Goal:** `src/belay/trace.py` can append one well-formed `claim` record to a closed trace.
- **Prerequisites:** none.
- **Files:**
  - Create `tests/test_trace_claim.py` (RED first — spec acceptance 1–4):
    1. envelope: `v:1`, `kind:"claim"`, `seq == last+1`, `observation_point:"session"`, `t_in` present;
    2. `text` present when given, key **absent** (never `""`) when not;
    3. missing file / empty file / invalid last `seq` → named error (a `TraceClaimError`-style
       class in `trace.py`), never silent;
    4. two appends → strictly increasing `seq` (no duplicate, no gap).
  - Modify `src/belay/trace.py`: the helper + named error. It reads the last line for the
    prior `seq` (strict monotonicity), reuses `_now`, writes the envelope exactly as
    `_append_locked` does except `observation_point: "session"`.
- **Validation:** `uv run pytest tests/test_trace_claim.py tests/test_trace.py`
- **Commit:** `feat(trace): append_claim_record — post-close claim appender`

### Phase 2 — Format documentation

- **Goal:** `TRACE_FORMAT.md` documents the `claim` kind.
- **Prerequisites:** Phase 1.
- **Files:** `docs/technical/TRACE_FORMAT.md` — the `claim` record: fields (`kind`, `text`
  absent-never-empty), observer (`observation_point: "session"` — the driver, never the
  proxy), append rule (seq = last+1, strict increase; named error otherwise), and that it is
  a non-frame record: skipped by readers, never replayed. Follow the doc's existing
  unknown-kind rule section (`:272-278`).
- **Validation:** read-through; suite untouched.
- **Commit:** `docs(trace): the claim record kind — fields, observer, append rule`

### Phase 3 — Tolerance pinned as contract

- **Goal:** prove by test that existing readers and replay are inert to claim records.
- **Prerequisites:** Phase 1.
- **Files:** extend `tests/test_trace_claim.py` (spec acceptance 5–6):
  5. a trace with a claim record indexes identically to the same trace without it (same
     derived records, no new `index_gap`);
  6. replaying a turn of a claim-bearing trace reproduces the same verdict as without.
  If the tests pass immediately, they are contract pins, not failures — record that in the
  commit message honestly. If a bug surfaces, fix it in this phase.
- **Validation:** `uv run pytest tests/test_trace_claim.py tests/test_replay*.py`
- **Commit:** `test(trace): claim records are inert to indexing and replay`

### Phase 4 — Driver wiring + pinned-hash guard update

- **Goal:** the minting driver records the claim at session close.
- **Prerequisites:** Phases 1–3.
- **Files:**

  - Modify `eval/minting_driver/batch.py`: keep the `Transcript` from `run_session`

  - Shared helper (in `capture.py` or a new small module) so any single-instance path uses
    the same code — check `eval/minting_driver/{cli,entrypoint}.py` for session paths
    outside `run_mint`; wire them if they exist.
  - **Pinned-hash guard:** find the test pinning `loop.py`/`batch.py` content hashes (search

- **Validation:** `uv run pytest tests/test_minting_driver_claim.py` then the full suite:

- **Commit:** `feat(mint): the claim record is appended at session close`

## Testing strategy

- Unit: spec acceptance 1–10 as the failing tests, written before each phase's code.
- Integration: the driver test drives `run_mint` with fakes (no subprocess, no model, no
  network) and proves the record lands in the trace that `phase0 run` will later read.
- Full suite `uv run pytest` after every phase (baseline 1501).
- Deterministic: `seq` derives from file content, not wall clock; `t_in` never enters a hash
  (existing rule); no network anywhere.

## Environment & determinism

- No env vars, no services, no new deps.
- The helper's only ambient input is the trace file itself — deterministic by construction.

## Edge cases & error handling

| Case | Behavior |
|---|---|
| Trace file missing / empty / last `seq` unparseable | Named error raised to the driver; never silent |
| `Done` with empty/whitespace `reason` | Claim record written with `text` **absent** |
| `max_steps` / error termination | **No** claim record (nothing was claimed) |
| Double append | Fresh `last+1` read each call → strictly increasing, test 4 |
| Writer still alive | Out of contract — documented: append only after the proxy exits |
| Old readers | `claim` is a non-frame record; already skipped (`index.py:110`); pinned in Phase 3 |
