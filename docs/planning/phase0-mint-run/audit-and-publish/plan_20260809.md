## 1. Decisions fixed before the audit

| # | Decision | Reasoning |
|---|---|---|
| **S-1** | The auditor is the owner; agents prepare evidence, never judgments | The auditor is the person who needs ≥3 TPs (pre-registration is a timing control, not an independence control — `PHASE0_RESULTS.md:63-65`) |
| **S-2** | Sampling rule (only if >30 flags): all control flags + all first-flag-in-instance + a random sample of the remainder, seed committed beside the sample; unaudited count stated | PRD req. 9, pre-registered |
| **S-3** | Root-cause keys are kebab-case and per-TP; independence is read off `(instance, tool)` pairs | The criteria's "independent" clause must be auditable by a stranger |
| **S-4** | The decision line is written by the owner AFTER the audit evidence is committed | The gate is the owner's call, on committed evidence |

## 2. Phases

### Phase 1 — Evidence inventory (agent-executed)

- **Goal:** every flag collected, de-duplicated, and readable in one place.
- **Files:** `audit-and-publish/FLAGS.md` (NEW): per stage — flagged instances, flagged turns
  (index, tool, sub-verdicts, causes), corpus case ids, the pre-registered sampling outcome
  (full or sample + seed), and for each TP candidate the replay diff excerpt.
- **Validation:** FLAGS.md's case ids match `belay corpus list` output exactly; turn indices
  match the ledgers' `flagged_turns`.
- **Commit:** `audit: the flagged inventory, from the committed ledgers`

### Phase 2 — The hand-audit (owner; main thread)

- **Goal:** every flag adjudicated; TPs labeled with root causes.
- **Files:** `audit-and-publish/AUDIT.md` (NEW): per flag — TP / FP / unverifiable, the
  evidence read (trace + replay diff), and for TPs the `(instance, tool)` pair and root-cause
  key. `belay corpus label` applied to each audited case (TPs require `root_cause`).
- **Validation:** `uv run belay corpus score` prints precision/recall with a real
  denominator; every TP has a root cause; the FP rate is stated even if unflattering.
- **Commit:** `audit: every flag adjudicated, root causes recorded`

### Phase 3 — Hand-replay of one FAIL (owner, with an agent operating the commands)

- **Goal:** the symmetric FP guard's second half — the delta is real, not a rename/manifest
  artifact.
- **Files:** `audit-and-publish/HAND_REPLAY.md` (NEW): the chosen FAIL, its trace, the replay
  command, the observed delta vs the recorded delta, and the verdict under the restored
  pre-state.
- **Validation:** the replayed verdict equals the ledger's; the delta is concrete (paths +
  content), not a wiring echo.
- **Commit:** `audit: one FAIL hand-replayed, its delta confirmed real`

### Phase 4 — Reproducibility check (agent-executed)

- **Goal:** a stranger can re-derive the number from the repo.
- **Files:** none (verification only) + `audit-and-publish/REPRODUCIBILITY.md` (NEW, short).
- **Procedure:** in a clean checkout/worktree of the branch, run `uv run belay phase0 report
  docs/planning/phase0-mint-run/mint-run/ledgers/s4c.json` and assert the headline, FP rate,
  and per-cause UNVERIFIED match the committed `acceptance-stage3.out` verbatim; repeat for
  the stage-1/2 ledgers.
- **Validation:** byte-identical headline numbers; any mismatch is STOP — reconcile the
  artifact, never edit the output.
- **Commit:** `audit: the number is re-derivable from the committed ledgers`

### Phase 5 — The decision line (owner; main thread)

- **Goal:** PROCEED or PIVOT, written as plainly as the other, on the canonical criteria
  (`PHASE0_RESULTS.md:17-42`) with Rules B and C applied as applicable.
- **Files:** `docs/technical/PHASE0_RESULTS.md` (dated decision section; no published number
  re-derived except by the gate decision), `docs/technical/PHASE0_AUDIT.md` (new-audit
  correction block if the audit changes any prior figure — only via the dated-correction
  convention), `docs/ROADMAP.md` (R1 row + gate blocks, dated), `CLAUDE.md` (status block,
  dated), `docs/technical/CAPABILITY_ROADMAP.md` (C5 gate status).
- **Disclosure set (mandatory):** rate with denominator; FP rate stated; UNVERIFIED by named
  cause; exposure summary (judged/zero/unrecorded) with Rule B's mechanical reading applied;
  pool composition; coverage limits (filesystem-only, shell exclusion, NOT_COVERED, MCP
  boundary); the ToS assumption; "reproducible" in the decided words; the ordering disclosure.
- **Validation:** the decision line states PROCEED or PIVOT verbatim; every disclosure bullet
  present; the diff is dated.
- **Commit:** `results: the Phase-0 gate decision — PROCEED (or PIVOT), on the pre-registered criteria`

### Phase 6 — RUNBOOK walk (agent-executed, integrator reviews)

- **Goal:** the reproduce-the-number artifact works end-to-end.
- **Files:** `docs/planning/phase0-corpus-run/RUNBOOK.md` (corrections committed).
- **Procedure:** follow the RUNBOOK from a clean state against the stage-2 artifacts; fix
  what the dig flagged (stale ledger example `:304-318`, stale case-id example `:348`) and
  anything the walk disproves; state in the commit which steps were walked.
- **Validation:** a fresh reader can reproduce `belay phase0 report` output from the RUNBOOK
  alone.
- **Commit:** `docs(runbook): walked end-to-end against stage-2 artifacts, corrections committed`

## 3. Edge cases

| Case | Handling |
|---|---|
| >30 flags | S-2 sampling; sample seed committed; unaudited count stated |
| A flag's replay is inconclusive | `unverifiable` label, stated; it neither helps nor hurts the TP count |
| Ledger/report mismatch in Phase 4 | STOP; reconcile the artifact — never edit the output |
| The audit contradicts a prior figure | Dated-correction block, never an edit of the published number |
| Near-zero with low exposure | Rule B: uninterpretable-about-agents reading written verbatim into the decision section |
| High rate | Rule C: controls + hand-replay evidence presented BEFORE the rate is published |

## 4. Agent execution notes

- Agents own Phases 1, 4, and 6 (evidence inventory, reproducibility check, RUNBOOK walk).
  Phases 2, 3, and 5 are owner-main-thread: adjudication, hand-replay, and the decision are
  human acts on committed evidence.
- Phase 1's agent must not label any case — labels are human (the engine's own rule,
  mirrored in the pipeline: the agent prepares, the owner judges).
- Checkpoints: after Phase 1 (inventory complete), after Phase 4 (reproducibility green),
  before Phase 5 (owner writes the decision on committed evidence).
