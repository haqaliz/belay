## 1. Decisions fixed before the run

| # | Decision | Reasoning |
|---|---|---|
| **S-1** | Probe **first**, code second | If auth breaks under `--safe-mode`, the decision flips to run-without-and-disclose; the TDD change would be reverted, and the probe evidence is committed either way |
| **S-2** | The probe uses the **full mint argv** + `--safe-mode`, from a **scrubbed env** (`env -i HOME PATH USER`), via `subprocess.run` | Re-verifies the P0b shape with the delta flag — auth must survive both the new flag and the env scrub, together |
| **S-3** | The probe is a **feasibility probe, not a measurement** — committed verbatim as a note, not under the two-commit freeze protocol | It decides an argv flag; it produces no number |
| **S-4** | `--safe-mode` joins the isolation flag block, next to `--strict-mcp-config` | Same semantic family (isolation of inherited state); `--bare` stays absent (breaks auth, P2) |

## 2. Phases

### Phase 1 — The probe (main thread; spend-incurring)

- **Goal:** decide the flag on evidence.
- **Files:** `docs/planning/phase0-mint-run/oracle-argv-safe-mode/probe-safemode.sh` +
  `probe-safemode.out` (NEW).
- **Probe** (committed script, then run once, output committed verbatim):
  ```bash
  env -i HOME=$HOME PATH=$PATH USER=$USER uv run python - <<'PY'
  import subprocess
  argv = ["claude", "-p", "Reply with the single word OK.",
          "--output-format", "json", "--model", "claude-opus-5",
          "--tools", "", "--strict-mcp-config", "--no-session-persistence",
          "--safe-mode", "--system-prompt", "You are a probe."]
  env = {"HOME": ..., "PATH": ..., "USER": ...}          # scrub ANTHROPIC_API_KEY et al.
  r = subprocess.run(argv, capture_output=True, text=True, env=env, timeout=600)
  print("exit:", r.returncode)
  print(r.stdout)
  print(r.stderr)
  # assertion line: "ANTHROPIC_API_KEY" in env is False
  PY
  ```
- **Validation:** the committed `.out` shows exit 0, `is_error:false`, `result:"OK"`, and the
  key-absence assertion; the `.sh` contains no output.
- **Commit:** `claude-cli: the --safe-mode probe, before and after (the flag survives auth, or it does not)`

## 3. Edge cases

| Case | Handling |
|---|---|
| Probe exit non-zero / auth fails | Decision flips (S-1): revert Phase 2's change, disclose in the PRD decision row, run without `--safe-mode` and document the reproducibility limit |
| Probe times out (600 s) | Setup/transient — re-run once, declared as such |
| `claude` CLI changed flag semantics | R-7 residual: the argv test catches absence, not meaning change; documented |
| Agent cannot build the RED test without running live | It must not run live — the `runner=` seam is the boundary; say so rather than weaken the assertion |

## 4. Agent execution notes

- Phase 1 is **main-thread only** (S-3, spend-incurring). The agent executes Phase 2; it must
  not run the probe, must not set `BELAY_EVAL_LIVE`, and must not write `probe-safemode.out`.
- The agent may read `tests/test_minting_driver_claude_cli.py` for the exact assertion style
  and must keep the one-flag-per-assertion granularity.
- Checkpoint: after Phase 2's commit, the suite must be green before Phase 3 starts.
