| # | Decision | Reasoning |

| **S-1** | The 7 real instances are the **first 7 fresh real records** of `selected.json`'s small-repo block (flask, requests, pylint, pytest, sphinx order) not in the excluded set; top up from django/sympy in file order only if needed | Fresh instances maximize information; file order is deterministic and auditable |

## 3. Edge cases

| Case | Handling |
|---|---|
| <7 fresh small-repo instances | Top up from django/sympy in file order; the header's `composition` states the spread; the test still passes (rule is mechanical) |
| A transcribed excluded id is not in `selected.json` | The script fails loud (assert the literal ⊆ selected ids) — a typo is caught, not silently dropped |
| Header/controls mismatch vs `CONTROL_RECORDS` | The test imports `CONTROL_RECORDS`; drift fails CI |
| Regenerating later changes files | Byte-stable by design; any future change is a visible diff with a reason |
