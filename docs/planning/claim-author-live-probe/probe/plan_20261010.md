## Testing strategy

- Deterministic: nothing in CI depends on the probe (manual-marked, excluded by
  `addopts`). The suite must stay at 2895/45/14.
- The manual test's own load-bearing assertions: axis engaged (`invocations >= 1`) and
  `claim`-key presence with a closed-vocabulary sub-cause or silence or verdict.
- Manual verification: the owner's single run; the freeze grep-check is itself the RED
  test of Phase A.

## Environment & determinism

`BELAY_CLAIM_AUTHOR`, `PROBE_MARKER`, `PROBE_WALL`, `BELAY_REFERENCE_AUTHOR_MODEL`
(owner-set, full model id). No clock/network/random in committed assertions; wall times
are recorded facts in the findings, never asserted. Engine replay is deterministic given
the pinned servers (committed run-3 shapes reused verbatim).

## Edge cases & error handling

- Model failure (quota/network) → `AUTHOR_EXITED_NONZERO` is a valid observation; the
  finding states R-D is NOT tested by it; re-run only on the owner's declared decision.
- Replay drift vs run 3 → recorded as a finding (instrument drift), never corrected
  silently.
- Missing `.manifests`/wrong server argv → the engine's fail-closed errors stand; the
  hazards are documented in `probe/README.md` so the owner's run does not rediscover
  them.
- A trace without a replayable final turn → the A3 path abstains
  `FINAL_STATE_UNOBSERVABLE` (a valid observation: the author never engaged, and the
  marker asserts it).
