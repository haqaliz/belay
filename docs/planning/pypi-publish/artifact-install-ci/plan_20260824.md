## 4. Testing strategy

- Unit: the module's six tests ARE the acceptance (lifted from PRD M1/M2/S3).
- Integration: the roundtrip test is end-to-end (proxy → snapshot → verify) against the
  installed artifact.
- Manual verification: `uv run pytest tests/test_artifact_install.py -m install -q`
  locally; the stranger-timing aspect covers the live-PyPI path.
- The suite stays green after each phase (`uv run pytest -q`).

## 5. Environment & determinism

- No network: `pip --no-index --no-deps`; the wheel/sdist are local files.
- No clock/random: the roundtrip fixtures are deterministic by construction (they are
  the docker inimage fixtures, already measured stable).
- Version truth: `pyproject.toml` only (parsed by regex, never imported).
- The repo `dist/` dir must stay wheel-free (docker clean-checkout property): the
  fixture builds into `tmp_path_factory` dirs and sweeps `dist/` before/after.

## 6. Edge cases & error handling

- **Landlock/seccomp unavailable (Linux host < 5.13):** `belay sandbox check` refuses
  with a named cause → `pytest.skip(f"{cause}")` — a skip with a named cause is the
  repo's accepted outcome; never fake a pass (the docker inimage precedent,
  `tests/test_docker_inimage.py:196-201`).
- **Seatbelt unavailable (macOS):** same shape — the check names the cause; skip with
  it.
- **`uv build` missing (contributor without uv):** let the test error with a clear
  message naming `uv build` as the requirement; do not silently skip — this is the
  acceptance, not an optional check.
- **A wheel that would install but stamps a wrong version:** the stamp test FAILs —
  that is the point (the `src/belay/__init__.py:3-14` drift history is the cautionary
  tale).
- **A third-party import leaking into the wheel:** the zero-dep subprocess test FAILs
  in the fresh venv — the enforcement `tests/test_import_guard.py` performs statically,
  this performs observationally.
- **Verify on a turn that cannot relocate/replay:** the engine's own honest
  UNVERIFIED-with-cause contract applies; the roundtrip test asserts a real PASS, so
  if the fixture arrangement is wrong the test fails rather than passing on an
  abstention.
