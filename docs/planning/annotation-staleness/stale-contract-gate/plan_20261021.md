## Task 1 — the per-call window helper

```python
def contract_invalidated(records, snapshot_seq, request_seq) -> Optional[int]
```

`snapshot_seq < seq < request_seq`, else `None`. Reuses `message_of` + `classify` (already
imported here). Rejects unreadable frames (no fabricated staleness).

- notification after the call → `None`;
