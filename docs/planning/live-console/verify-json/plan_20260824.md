## 2. The machine contract (pinned by the first RED test's fixture)

`belay verify --json` emits ONE JSON document to stdout. Shape (keys locked by the
committed fixture snapshot; deliberate changes are contract changes):

```jsonc
{
  "schema": 1,
  "trace": "<path as given>",
  "turns": [
    {
      "ordinal": 0,
      "tool": "write_note",
      "status": "PASS",                     // PASS|WARN|FAIL|UNVERIFIED (reduced)
      "cause": null,                        // named cause when UNVERIFIED
      "sub_verdicts": [
        {"axis": "A2", "kind": "replay",          "status": "PASS",         "message": "..."},
        {"axis": "A2", "kind": "effect",          "status": "PASS",         "message": "..."},
        {"axis": "A2", "kind": "effect:network",  "status": "NOT_COVERED",  "message": "..."},
        {"axis": "A1", "kind": "invariant", "rule": "no-assertion-weakening",
         "scope": "tests", "status": "PASS", "message": "...", "files_compared": 0}
      ]
    }
  ],
  "aggregate": {"turns_verified": 1, "PASS": 1, "WARN": 0, "FAIL": 0, "UNVERIFIED": 0},
  "coverage": {                                // ALWAYS present, even when empty
    "effect:network": {
      "not_observed_turns": 1, "of_turns": 1, "message": "..."
    }
  },
  "exposure": {"recorded": true, "judged_turns": 0, "comparisons": 0},
  "trajectory": {"status": "UNVERIFIED", "cause": "NO_CLAIM_RECORDED", "message": "..."},
  "error": null                                 // {"cause": "..."} on internal failure
}
```

- `--turn N`: `turns` holds exactly one record; `trajectory` is null (the human report
  suppresses the trajectory line on `--turn N`, `cli.py:653-666`).
- Internal failure: `{"error": {...}}` on stdout with the fields above absent/`null`,
  exit non-zero. Never a truncated `turns` document.
- Exit codes: identical with and without `--json`.

## 6. Edge cases & error handling

- **Internal failure mid-verify:** `{"error": {...}}` + non-zero exit (tested).
- **`--turn N` out of range:** same error path as text (ValueError → exit non-zero) —
  `{"error": ...}`.
- **No turns in trace:** `turns: []`, aggregate zeros, coverage present — never a
  missing coverage block.
- **Trajectory absent (older trace):** `"trajectory": null` — mirrors the text
  report's named-cause handling; never invented.
