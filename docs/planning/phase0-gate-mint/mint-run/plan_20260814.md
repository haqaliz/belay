## Runbook (the stages)

### Stage 1 — probe (2 controls: CTL-1 + CTL-4) · root `eval/mint/s6a`

1. Commit `mint-run/acceptance-stage1.sh` (invocation + env + protocol prose; NO result):
   ```bash
   export BELAY_EVAL_SERVER_ROOT="${BELAY_EVAL_SERVER_ROOT:-$PWD/eval/servers}"
   uv run python -m eval.minting_driver batch \
     --root eval/mint/s6a --registry eval/instances/s6stage1.json \
     --toolset filesystem+shell --provider claude-cli --model claude-opus-5 --max-steps 20
   ```
2. Run once: `bash mint-run/acceptance-stage1.sh | tee mint-run/acceptance-stage1.out`.
3. Verify (dual-server composition, aspect 1 — **`--shell-server` MUST precede `--server`**:
   `--server` is `nargs=REMAINDER` and would swallow every later argument, silently
   replaying everything against the filesystem server):
   `mkdir -p runs && uv run belay phase0 run eval/mint/s6a/batch --ledger runs/s6a.json
   --corpus-dir corpus/local --shell-server "node $PWD/eval/servers/node_modules/mcp-server-commands/build/index.js" --server node $PWD/eval/servers/node_modules/@modelcontextprotocol/server-filesystem/dist/index.js '{workspace}'`.
4. Commit verbatim `.out` + ledger `mint-run/ledgers/s6a.json` + `STAGE1_FINDINGS.md`
   (apply the CTL-4 outcome reading: PASS → launch; UNVERIFIED → adjudicate wiring-vs-steering,
   fix only for a wiring defect, declared re-run; FAIL → D-3 void).

### Audit + publication (after stage 3, or at the first stop that ends the mint)

1. **Full adjudication** (no sampling on the trajectory axis): every flagged turn and every
   trajectory FAIL/PASS → a written finding (`FLAGS.md`: per-instance facts, tools-availability
   from the trace, evidence, corpus ids); labels via `belay corpus label`; `belay corpus run` +
   `score` after; hand-replay any disputed control/flag (`HAND_REPLAY.md`); reproducibility
   (`REPRODUCIBILITY.md`: `belay phase0 report` re-renders each ledger to the published
   headline). Pattern: `docs/planning/phase0-remint/audit-and-publish/`.
2. **`PHASE0_RESULTS.md` update**: violation rate + denominator + FP rate + trajectory
   exposure (per instance: `claims_judged`/`claims_abstained`/causes) + UNVERIFIED-by-cause +
   per-turn FAIL rate; the R7 abstain-reclassification note; the controls-first + toolset +
   MCP-boundary coverage statements; the forecast comparison (29/65 vs realized judged).
3. **The gate decision line**: PROCEED (≥3 independent audited TPs + ≥50 + no INSTRUMENT
   SUSPECT) or PIVOT (reasons), recorded per the canonical block — never renarrated. If the
   run stopped early (D-1/D-3/stop-loss), that stop is recorded as the unit's result, not
   padded into a rate.
4. `eval/README.md` runbook update (dual-`--server` verify invocation; staged walk).
