## Decisions taken into this plan

**D1 — producer ii goes with the abstentions (i–iii), not with iv.** A tool absent from an
observed snapshot means *we have no observation of a contract for this tool*, which is a failed
attempt, not "no contract exists". Drafted as the default; spec open question 1 records the
counter-case. **If the owner reverses this, only Phase 3's predicate and Phase 1's AC-2 case for
producer ii change.**

**D2 — the discriminator is a purpose-built field, not `annotations_object`.** `annotations_object`
answers *absent object vs empty object*; both yield no `readOnlyHint`, so it is the wrong key for
*server-silent vs unobserved*. Add an explicit marker. (Spec open question 2.)

**D3 — `reduce`, `_RANK`, and `phase0/runner.py`'s `replayed_any` predicate are NOT touched.**
The reduced status becomes PASS on its own. Any diff to those files in this aspect is a defect.

## Testing strategy

- **Deterministic, no network.** Fake/fixture traces only; no live MCP server, no model call.
- Drive the **real** `render_effect_verdict` / `verify_turn`; never hand-build `Verdict` objects
  (the trap `tests/test_interop_attach.py:366-372` documents, and the reason a green suite was
  once not evidence).
- The full suite runs twice: Phase 0 (measurement) and Phase 6 (acceptance).

## Edge cases & the verdict each produces

| case | verdict |
|---|---|
| tool present in snapshot, no `annotations` object | `NOT_COVERED` (the new path) |
| tool present, `annotations` present, no `readOnlyHint` key | `NOT_COVERED` — same claim: the server declared no contract |
| `readOnlyHint: "yes"` (non-boolean) | `UNVERIFIED` — unchanged, a different branch |
| no `tools/list` before the call | `UNVERIFIED` — producer i, unchanged |
| tool absent from snapshot | `UNVERIFIED` — producer ii, per D1 |
| unreadable request frame | `UNVERIFIED` — producer iii, unchanged |
| declared-true + mutation | **FAIL** — unchanged, the axis keeps its teeth |
| boundary abstention (`TOOL_NOT_OFFERED` etc.) | `UNVERIFIED` — gate runs first, unchanged |
