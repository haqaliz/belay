## Edge cases & error handling

- The model ignores the steering and emits verification vocabulary anyway — the D-3 rule
  applies on real evidence; never re-steer mid-mint (freeze discipline). Documented in the
  composition note.
- The positive control's command fails in the contained run (sandbox denies, python3
  absent) — a recorded finding; the control's expected verdict is then adjudicated, not
  silently changed.
- Classifier vocabulary untouched — any test that imports the old CTL-2/CTL-3 task text
  must be updated as part of the intended change, not worked around.
