### Phase 1 — RED: composite transport acceptance

- **Goal:** Failing tests for the new `CompositeTransport` before it exists.
- **Prerequisites:** Read the existing shapes first: `eval/minting_driver/transport.py`
  (`StdioMcp` protocol), `fakes.py`, `tests/fixtures/shell_command_server.py`, and how the
  loop drives one transport (`loop.py` `run_task`).
- **Files to create/modify:** `tests/test_minting_driver_composite.py` (new).
- **Tests (RED):**
  1. Merged tool list: two fake sessions (fs tools + `run_process`) → one flat list, names
     verbatim (assert `run_process` present, un-prefixed).
  2. Routing: `tools_call("read_text_file", …)` hits the fs session's fake only;
     `tools_call("run_process", …)` hits the shell session's fake only; replies
     byte-identical to the direct session.
  3. One call in flight across the composite: a second `request` while the first is
     unresolved raises (mirror `StdioMcp`'s control-flow guarantee, `transport.py:210-215`).
  4. Error containment: a session whose process died surfaces an error on its own call; the
     other session still serves.
  5. `close()` terminates both sessions.

### Phase 2 — GREEN: composite transport

- **Goal:** `eval/minting_driver/composite.py` passes Phase 1.

## Edge cases & error handling

- Unknown tool name → composite raises a clear error (never routes to the wrong session).
- A session that dies mid-call → that call errors; other session unaffected; `close()`
  idempotent.
- Duplicate tool names across sessions (e.g. both servers declaring `read_text_file`) —
  decide: fs wins (first-session precedence, documented) — the composite's routing map
  keeps first-wins and the merged list dedupes, documented in the module docstring.
- Shell turns in replay: shipped relocation handles `command_line`/`argv`/`cwd`; a shell
  turn that cannot relocate is UNVERIFIED (`EMBEDDED_PATH_UNRELOCATABLE`) — never a silent
  miss (already shipped; no code change).
- `--toolset` absent → exactly today's behavior (the s5 freeze scripts re-run identically).
