## Edge cases & error handling

- No snapshot, stale snapshot → `TOOLSET_UNKNOWN` (never FAIL, never a guess).
- Snapshot after the claim → not ability (test 7).
- Unclassifiable claim + fs-only tools → `CLAIM_UNCLASSIFIABLE`, not the toolset cause
  (claim checks precede; test 6).
- Every UNVERIFIED path has a named cause; disposition/report/ledger semantics unchanged
  (UNVERIFIED never flags; ledger absent-never-zero).
