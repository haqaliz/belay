## 2. Phases (TDD, commit per phase)

### Phase 1 — RED: `tests/test_calibration.py`
1. `reliability_curve`: a hand-computed fixture — rows with known (confidence,
   violated) spread across deciles; assert per-bin n, mean confidence, observed rate
   EXACTLY (the values computed by hand in the test, not by the code).
2. **Equal-width decile bins** pinned: bin edges [0.0-0.1) … [0.9-1.0]; a confidence
   of exactly 1.0 falls in the last bin.
3. Empty bin ⇒ rate `None` and a `"no data"` marker, never 0.
4. `ece`: hand-computed ECE over the same fixture, exact.
5. `threshold_sweep`: candidates at 0.3/0.5/0.7 — violations-skipped and
   budget-saved per candidate, exact; top-N sweep over N = 1..3, exact; tie-break by
   lowest ordinal (mirror the budget aspect).
6. Determinism: the same input twice ⇒ identical output; no clock/randomness imports
   (assert the module's import list structurally, stdlib only).
7. 0-denominator: an empty rows set raises a named error (the caller refuses before
   computing — never returns a fabricated 0).
Run `uv run pytest tests/test_calibration.py -q` — RED (module absent). Commit:
`git add tests/test_calibration.py && git commit -m "test(calibration-math): RED —
the reliability curve, ECE, and sweep exact pins"`

### Phase 2 — GREEN: `src/belay/verify/calibration.py`
- `LedgerRow(ordinal, score, confidence, violated)` — frozen dataclass.
- `reliability_curve(rows)` — decile bins; per bin: n, mean confidence, observed
  rate (`None` for n=0); deterministic iteration order.
- `ece(rows)` — Σ over non-empty bins of (n_bin/N × |rate_bin − conf_bin|).
- `threshold_sweep(rows, candidates)` — violations-skipped = violated rows with
  score < threshold; budget-saved = skipped/total; plus `top_n_sweep(rows, ns)`.
- Rate discipline: `None` for 0-denominator, never 1.0. No clock, no randomness, no
  filesystem, no network. Docstrings state the honesty contract: the measurement is
  over the turns actually replayed; calibrated ≠ caused.
Run: `uv run pytest tests/test_calibration.py -q` (GREEN), then
`uv run pytest tests/test_verify_zero_llm.py -q` (the new module is auto-scanned
under `verify/` — stdlib only). Commit: `git add src/belay/verify/calibration.py &&
git commit -m "feat(calibration-math): reliability curve, ECE, and the sweep — stdlib,
None-for-zero, deterministic"`
