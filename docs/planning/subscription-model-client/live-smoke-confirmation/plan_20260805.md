## 1. Decisions fixed before the run

| # | Decision | Reasoning |
|---|---|---|
| **S-1** | **Instance: a `pytest-dev/pytest` instance** from `eval/instances/pool.json`, and **not** one of the 15 already banked | pytest's tests live under `testing/`, which the shipped A1 scope covers, and pytest scored **6/7** on the exposure text signal — the highest with a meaningful denominator. Choosing an unbanked instance keeps the run clean of the fitted-on confound |
| **S-2** | **`--no-ingest`** | `phase0 run` otherwise banks flagged turns as corpus cases. A single unadjudicated smoke turn must **not** enter the corpus: the corpus is the regression suite, and an unlabeled case from a one-off run is noise at best. The flag shipped in v0.11.0 for exactly this |
| **S-3** | **Freeze protocol.** Commit the test (containing no result) **first**; run once; commit the verbatim output **second** | Same discipline as every measured number in this repo. It is what makes the result re-derivable rather than asserted |
| **S-4** | **Run once.** A red is a finding to fix, not a draw to repeat | Re-rolling after seeing a result is the anti-re-roll contract's whole subject |
| **S-5** | **The criterion is that the TRAJECTORY reaches a real write**, never that the *first* call is one | Probed 2026-08-05: given an edit task the oracle **read the file first**. That is correct agent behaviour, not the STAGE2 "did nothing" failure |
| **S-6** | The main thread runs the live invocation, not a subagent | It is the irreversible, outward-facing, spend-incurring step and the unit's exit criterion. I report what happened first-hand |

## 2. Phases

### Phase 1 — The smoke test (tooling only, contains no result)

- **Goal:** a `manual`-marked test that drives one instance end to end. **Written and committed
  before it is ever run.**
- **Files:** `tests/test_minting_driver_claude_cli_smoke.py` (NEW).
- **Guard — copy verbatim** from `tests/test_minting_driver_smoke.py:111-121`:
  ```python
  pytestmark = [
      pytest.mark.manual,
      pytest.mark.skipif(
          not (sys.platform == "darwin" and os.environ.get("BELAY_EVAL_LIVE") == "1"),
          reason=(...),
      ),
  ]
  ```
- **Shape:** `run_mint` (or the narrowest equivalent the existing smoke uses) with
  `--provider claude-cli`, an **explicit** `--model`, `--no-ingest`, one instance, then assert:
  1. the capture exists and the **stock** `belay phase0 run` resolves it;
  2. **`INSTRUMENT SUSPECT` did not fire**;
  3. at least one recorded `tools/call` is a **write** to a file (the trajectory criterion, S-5);
  4. the recorded provenance names `claude-cli` and the exact model;
  5. **no API key** appears in the recorded provenance or the child env.
- **Validation:** default `uv run pytest` shows it **DESELECTED** (not merely marked) — count goes
  `1 deselected` → `2 deselected`. That is criterion 8, and it is the only thing that proves the
  CI-exclusion mechanism rather than assuming it.
- **Commit:** `smoke(claude-cli): the invocation, frozen before it has been run`

### Phase 2 — Run it, once

- Exported for the run only:
  `BELAY_EVAL_LIVE=1`,
  `BELAY_EVAL_SERVER_ROOT=/Users/aliz/dev/at/belay/.claude/worktrees/feat-phase0-mint-execution/eval/servers`
- `uv run pytest tests/test_minting_driver_claude_cli_smoke.py -m manual -q` (or `-p no:cacheprovider`
  as the existing smoke does, if it does).
- Capture **stdout verbatim** to `docs/planning/subscription-model-client/live-smoke-confirmation/acceptance.out`,
  alongside the invocation in `acceptance.sh`.
- **Commit:** `smoke(claude-cli): the measurement, verbatim, run once`

### Phase 3 — Record the reading

- Apply **PRD §2.1 Rule A** to whatever happened. Write the outcome into the aspect spec and add a
  dated note to the PRD. State the wall-clock and the model.
- If **green**: publish as *"the path works at n=1"* — **never** *"edit quality is good"*.
- If **red**: publish the red, name which Rule A row it matched, and record that the mint stays
  unfunded (D-7). **Do not re-run.**
- **Commit:** `docs(smoke): what the one live instance showed, and what it does not`

## 3. Edge cases

| Case | Handling |
|---|---|
| `MissingServerError` | `$BELAY_EVAL_SERVER_ROOT` is unset or wrong. A **setup** failure, not a result — fix and re-run; the anti-re-roll rule applies to *results*, not to a run that never happened |
| `git clone` fails | Network/setup failure. Not a result |
| Oracle returns `Done` immediately | **A real result** — the STAGE2 shape. Rule A row 2: do not launch a batch |
| Oracle only reads, never writes | **A real result.** Same row |
| Unparseable reply | A **client** defect, not a model verdict. Criterion 3 should already have raised |
| Capture exists but `INSTRUMENT SUSPECT` | **Wiring** report, never a result. `bridge_capture` is the load-bearing test |
| Turn replays FAIL | An acceptable outcome — report it. Execution evidence only; **no adjudication** here, and no rate quoted from n=1 |
| Wall-clock runs long | Expected. The client timeout is 600 s per invocation and `DEFAULT_MAX_STEPS` is 12 |

## 4. Agent execution notes

- **Phase 1 goes to an agent. Phase 2 does not** (S-6).
- The agent must **not** run the live test, must **not** set `BELAY_EVAL_LIVE`, and must **not**
  create `acceptance.out`. Writing a result file before the run would defeat the freeze protocol.
- If Phase 1 cannot assert something without running live, it should **say so** rather than weaken
  the assertion into something vacuous.
