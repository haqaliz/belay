## 1 · Design decisions (settled — do not re-litigate mid-build)

1. **New subcommand, mirroring correlate.** `belay interop export <otlp> <trace>
   [--server CMD…] [--manifest-dir DIR] [--replays N] [--timeout S] [--out FILE]
   [--json]`, registered in the existing `interop` argparse group (`cli.py:2886-2936`)
   as a sibling of `correlate` (`:2890-2936`). Handler `_cmd_interop_export`,
   modeled on `_cmd_interop_correlate` (`cli.py:2211-2284`) — same lazy imports, same
   fail-closed preflight (directory trace arg, missing trace, missing otlp,
   `TraceCorrupt`, `OtlpParseError` — each `_emit` + return 2), same `_worst`-free
   semantics (see #3).
2. **Streams:** the OTLP/JSON document → `--out FILE` (write text, utf-8, trailing
   newline) or **stdout** when `--out` is absent; the summary (human or `--json`) →
   **stderr** always. stdout carries exactly one artifact (AC2/AC4). When `--out` is
   given, the summary still goes to stderr; when it is not, the summary is stderr too.
3. **Exit semantics:** rc 0 on successful export **regardless of verdict contents** (an
   all-UNVERIFIED export is still a successful export — verdict contents never gate);
   rc 2 on the operational fail-closed errors (mirroring correlate's preflight returns);
   rc 1 on a write failure (e.g. `--out` into an unwritable path) — a distinct code so
   the three states are distinguishable. **This deliberately diverges from correlate's
   `_worst`-based exit**; the export is not a gate.
4. **Pipeline:** identical to correlate through `correlate_and_attach` (with `--server`
   → `correlate_and_attach`; without → `_correlate_without_server`), then
   `build_enriched_document(document, spans, results)` where `document` is the original
   `json.loads(otlp_path.read_text(...))` (the same bytes `parse_otlp` read), then
   serialize with the engine's settled formatting
   (`json.dumps(..., sort_keys=True, indent=2)` + trailing newline — the byte-stable
   contract lives in `export.py`; the CLI must call the same serializer, so the
   serialization helper lives in `export.py`, not the CLI).
5. **Summary content** (stderr): a human block mirroring `report.render`'s honest style —
   the export path (or `-` for stdout), the correlation rate `matched/total` with
   denominator, the uncorrelated buckets by named cause, and — when no `--server` was
   given — the "no --server given: correlation ran, but no turn was replayed -- every
   matched span reports UNVERIFIED, never a guessed PASS" line, adapted to export.
   `--json` emits `{"export": "<path|->", "correlation": {...}}` (the
   `correlation_summary` shape from `report.py:50`), stdlib-serialized.
6. **Help text** carries the honesty line: "spans that cannot be replayed export as
   UNVERIFIED, never PASS" (AC5).

## 2 · Phases

Each phase is RED → GREEN → REFACTOR and leaves the suite green.

### Phase 1 — RED: the CLI contract tests, written FIRST

- **Goal:** pin the surface before the handler exists (AC1–AC5; AC6's seatbelt test
  included here, it is part of the contract).
- **Files:** `tests/test_interop_export_cli.py` (new).
- **Tests** (model on `tests/test_interop_cli.py`; use `cli.main([...])` + `capsys`,
  and the subprocess pattern for help):
  - `test_ac1_export_writes_a_parseable_document` — end-to-end with the stub-free path
    **without** `--server` (no replay needed): `_correlate_without_server` marks every
    span UNVERIFIED; the exported file parses with `parse_otlp` and every span carries
    `belay.verdict.status`.
  - `test_ac2_stdout_is_the_document_only` — no `--out`: `capsys.readouterr().out`
    parses with `json.loads` as the OTLP document; the summary text is on `.err`; no
    summary string appears in `.out`.
  - `test_ac3_exit_codes_fail_closed` — parametrized: missing otlp file → 2 + named
    message; missing trace → 2; malformed OTLP → 2; directory trace arg → 2 (same
    message as correlate); `--out` into a nonexistent directory → 1 + named message.
  - `test_ac3_success_exit_ignores_verdict_contents` — an all-UNVERIFIED export (no
    `--server`) exits **0** (asserted against correlate's behavior, which would exit 1 —
    this divergence is deliberate and pinned).
  - `test_ac4_json_summary_on_stderr` — `--json` with `--out`: `.err` parses with
    `json.loads`, carries `export` + `correlation` (`matched`/`total`/`uncorrelated`);
    `.out` is empty (the document went to `--out`).
  - `test_ac5_help_states_unverified_never_pass` — subprocess `--help` contains the
    honesty line.
  - `test_ac6_end_to_end_matched_turn_exports_real_pass` — seatbelt-gated
    (`_REQUIRES_SEATBELT` pattern, `test_interop_cli.py:306-309`): the real replay path
    with `--server` on the fixture filesystem server; the matched span's exported
    `belay.verdict.status == "PASS"` and the coverage key is present per the verdict.
- **Validation:** all FAIL against today's code (no `export` subcommand exists — RED).
- **Commit:** `test(interop): RED — the export CLI contract: streams, exit codes, help, fail-closed`

### Phase 2 — GREEN: the subcommand

- **Goal:** `belay interop export` that makes Phase 1 green.
- **Files:** `src/belay/cli.py` (add `export` subparser beside `correlate` in the
  `interop` group; add `_cmd_interop_export` beside `_cmd_interop_correlate`).
- **Details:** replicate `_cmd_interop_correlate`'s preflight and lazy-import style;
  share `_correlate_without_server`; reuse `default_manifest_dir_for`; call
  `export.build_enriched_document` + `export.dumps` (the serializer in `export.py`);
  write via `Path.write_text` with a try/except returning 1 on `OSError`; emit summary
  with `_emit(..., err=True)` if that helper supports it — otherwise the existing
  `_emit` targets stdout, so check `cli.py`'s `_emit` signature first and route the
  summary to stderr via `print(..., file=sys.stderr)` in the handler.
- **Validation:** `uv run pytest tests/test_interop_export_cli.py -q` → green;
  `uv run pytest -q` full suite green (the flag-parity guard must stay green — if the
  guard requires flags to be declared on both replay-bearing surfaces, `--server` on
  export must be declared like correlate's).
- **Commit:** `feat(interop): belay interop export — verdicts into a fixture collector`

## 5 · Environment & determinism

- None. The exported document is deterministic (engine aspect); the CLI adds only I/O.
- The seatbelt-gated test is the only one that touches real replay; it stays darwin-gated
  with the named cause (same as correlate's).

## 6 · Edge cases & error handling

| Case | Behavior |
|---|---|
| Missing otlp / trace file | rc 2, named message (mirrors correlate) |
| Malformed OTLP | rc 2, `OtlpParseError` text |
| Directory trace argument | rc 2, the "pass a single trace file" message |
| `--out` unwritable path | rc 1, named message (distinct from 2) |
| No `--server` | correlation only; every span exports UNVERIFIED; rc still 0; the honesty line prints on stderr |
| `--json` without `--out` | document on stdout, machine summary on stderr (both asserted) |
| Flag-parity guard | `--server` declared on export like correlate's |

## 7 · Agent execution notes

- Check `_emit`'s signature in `cli.py` first — if it prints only to stdout, route the
  summary to stderr explicitly; do not silently mix streams.
- Reuse `_correlate_without_server` rather than re-implementing the no-server path.
- The divergence from correlate's exit code (rc 0 on all-UNVERIFIED) is deliberate and
  pinned by `test_ac3_success_exit_ignores_verdict_contents` — do not "fix" it to match
  correlate.
- Checkpoint for the integrator: Phase 1 RED committed before the handler exists; the
  seatbelt test runs only on darwin and is validated by the integrator, not CI-less.
