## 1 · Design decisions (settled — do not re-litigate mid-build)

1. **Positional pairing, not keying.** `correlate_and_attach` returns one `CorrelatedSpan`
   per input span, in input order (`attach.py:158-208`); `parse_otlp` preserves document
   order. The export pairs `results[i]` with `spans[i]`, asserting equal lengths. The
   attach boundary, `CorrelatedSpan`, and the `--json` report are **untouched** (AC9).
2. **The exported document is a deep copy; inputs are never mutated.** `copy.deepcopy`
   of the parsed document dict; enrich the copies; the input must deep-equal after the
   call (AC5).
3. **Every ingested span is marked.** Matched → the real `TurnVerdict` verbatim; uncovered
   → `UNVERIFIED` + the span's named `cause` (`no-matching-mcp-turn` /
   `ambiguous-correlation` / `unrestorable-pre-state` / replayed causes carried through).
   No span is exported bare (AC7).
4. **Attribute contract** (settled; the byte-stable fixture pins it):
   - `belay.verdict.status` — `CorrelatedSpan.status` (reduced status, `.value`).
   - `belay.verdict.axis` — the `axis` of the highest-ranked sub-verdict by the rank
     table in `verdict.py:67-73` (FAIL > UNVERIFIED > WARN > PASS; NOT_COVERED never
     ranks — it is filtered first), **first among ties**; absent when the verdict has no
     sub-verdicts (uncovered spans).
   - `belay.verdict.cause` — the span's `cause`; **absent when None, never `""`**.
   - `belay.verdict.turn_index` — int; matched spans only (absent otherwise).
   - `belay.verdict.coverage` — JSON string array of `kind` values of sub-verdicts whose
     status is `NOT_COVERED` (e.g. `["effect:network"]`); **absent when none**.
   - `belay.verdict.sub_verdicts` — JSON string array of `{"axis","kind","status",
     "message"}` (a plain dict per sub-verdict, `.value` for status); **absent when
     empty** (uncovered spans).
   - Span event `belay.verdict` — `timeUnixNano` = the span's own `start_time_unix_nano`
     (deterministic, from the input); attributes: `message` (the worst sub-verdict's
     message; empty string if none) and, where present, `observed`/`expected` of that
     same sub-verdict (JSON-stringified via `json.dumps` if not already a string).
5. **Serialization** — `json.dumps(enriched_document, sort_keys=True, indent=2)`,
   written with a trailing newline. Byte-stable (AC6). OTLP attribute value objects keep
   the shape the parser reads: `{"key": ..., "value": {"stringValue": ...}}` for strings,
   `{"intValue": str(n)}` for ints (matching `spans_ok.json`).
6. **Attribute insertion order** — attributes are appended to the span's existing
   `attributes` list; the `belay.*` keys sort deterministically because the serializer
   sorts keys; a collector sees no order dependence.
7. **Worst sub-verdict for the event** — same ranking as #4's axis; `reduce()` filters
   NOT_COVERED before ranking, so the worst sub-verdict is never a NOT_COVERED one.

## 2 · Phases

Each phase is RED → GREEN → REFACTOR and leaves the suite green.

### Phase 1 — RED: the honesty + contract tests, written FIRST

- **Goal:** pin the contract before any code exists: round-trip (AC1), UNVERIFIED-never-PASS
  (AC2), coverage (AC3), absent-never-zero (AC4), purity+determinism (AC5), pairing (AC8).
- **Files:** `tests/test_interop_export.py` (new).
- **Tests** (model on `tests/test_interop_attach.py` patterns — `_span()` helper,
  `trace_of(tmp_path, frames)` from conftest, `verify=` stub seam):
  - `test_ac1_round_trip_status_and_axis_intact` — build a trace with a canonical
    `TRACE_CONTEXT_META` frame + one `tools/call`; a spans doc with one matching span;
    `correlate_and_attach(..., verify=fake_verify)` returning a known `TurnVerdict`
    (constructed directly, e.g. status FAIL with one A2 sub-verdict); run
    `build_enriched_document`; re-parse the export with `parse_otlp`; assert the span's
    `belay.verdict.status == "FAIL"` and `belay.verdict.axis == "A2"`.
  - `test_ac2_unmatched_span_exports_unverified_never_pass` — one span whose ids match
    nothing; assert `belay.verdict.status == "UNVERIFIED"`, `cause ==
    "no-matching-mcp-turn"`, and **no** `belay.verdict.turn_index` key.
  - `test_ac2_ambiguous_span_exports_unverified_never_pass` — same shape via the
    `Ambiguous` path (re-used span id across two turns); cause `ambiguous-correlation`;
    `verify` is `_never_call`.
  - `test_ac3_coverage_line_survives` — a `TurnVerdict` with a `NOT_COVERED` sub-verdict
    (`kind="effect:network"`); assert `belay.verdict.coverage == '["effect:network"]'`;
    and a PASS verdict with no NOT_COVERED sub-verdict → **no** coverage key.
  - `test_ac4_absent_never_zero` — PASS verdict with no cause → no `belay.verdict.cause`
    key, never `""`; uncovered span → no `belay.verdict.sub_verdicts` key.
  - `test_ac5_inputs_unmutated` — deep-copy the document and spans before the call;
    assert deep-equal after.
  - `test_ac5_two_runs_byte_identical` — call twice, `json.dumps` both, assert equal.
  - `test_ac8_shared_span_id_across_traces_gets_its_own_verdict` — two spans with the
    same `span_id`, different `trace_id`, one matched to turn 0, one unmatched; each gets
    its own status.
  - `test_ac8_length_mismatch_is_loud` — `results` truncated by one → the function
    raises (assert `ValueError` with a message naming the pairing), never a silent zip.
  - `test_ac7_no_span_exported_bare` — every span in the exported document carries
    `belay.verdict.status`.
- **Validation:** all tests FAIL against today's code (no `export.py` exists — RED).
- **Commit:** `test(interop): RED — the export contract: round-trip, UNVERIFIED-never-PASS, coverage, absent-never-zero`

## 5 · Environment & determinism

- None. No env vars, no network, no clock: the only timestamp in the output
  (`timeUnixNano` on the event) is copied from the input span.
- Determinism is asserted two ways: byte-identical re-runs (AC5) and the committed
  fixture (AC6).

## 6 · Edge cases & error handling

| Case | Behavior |
|---|---|
| `len(spans) != len(results)` | `ValueError` naming the pairing (AC8) — never a silent partial zip |
| Uncovered span (unmatched/ambiguous) | `UNVERIFIED` + named cause; no axis, no turn_index, no sub_verdicts keys |
| No `cause` on a matched span | No `belay.verdict.cause` key (absent-never-zero) |
| No `NOT_COVERED` sub-verdicts | No `belay.verdict.coverage` key |
| Empty `sub_verdicts` | No `belay.verdict.sub_verdicts` key |
| Sub-verdict `observed`/`expected` non-string | JSON-stringified into the event; never dropped |
| Verdict with only NOT_COVERED sub-verdicts | Reduced status is `UNVERIFIED` (via `reduce`) — axis absent, coverage present |
