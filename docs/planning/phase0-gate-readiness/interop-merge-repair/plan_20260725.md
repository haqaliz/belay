## Phase 2 — RED: pin the fabricated cause (defect 2a)

**Goal:** a failing test that proves interop mislabels a replayed turn. **This is the
load-bearing test of the whole PR.**

**Prerequisites:** Phase 1.

**Files to create/modify:** `tests/test_interop_attach.py`

**The trap to avoid, stated explicitly.** The existing
`test_matched_replayed_pass_turn_has_no_bespoke_cause` passes a stub through the `verify=`
seam (`attach.py:106`) and hand-builds `TurnVerdict(..., cause=None)`. It is green before and
after the bug. **A new test written the same way is worthless.** The new test must produce a
`TurnVerdict` whose `cause` is set *by the real code path* — either by calling the real
`verify_turn` against a fixture trace whose turn replays and reduces to `UNVERIFIED`, or, if
that is too heavy, by driving the real `_replayed_cause` to build the verdict rather than
hand-writing `cause=`.

**The test:**
```
given  a turn that REPLAYS and reduces to UNVERIFIED (so cause is a REPLAYED_* bucket)
when   correlate_and_attach resolves a span matching it
then   the CorrelatedSpan's cause is NOT unrestorable-pre-state
```

**Validation:** `uv run pytest tests/test_interop_attach.py -q` → **fails**, with the
CorrelatedSpan carrying `unrestorable-pre-state`. If it passes, the test is wrong (almost
certainly stubbed) — fix the test before writing any production code.

**Commit:** `test(interop): RED — a replayed-but-unverified turn is not an unrestorable pre-state`

## Phase 3 — GREEN: discriminate the non-replayed path structurally

**Goal:** `attach.py` stops inferring "was this replayed?" from the mere presence of `cause`.

**Prerequisites:** Phase 2 RED.

**Files to modify:** `src/belay/interop/attach.py` (`:134–139`, and the `:25–33` docstring).

**Why the obvious fixes don't work — read before choosing:**
- ❌ *Discriminate on `(axis, kind)`.* The non-replayed sub-verdict uses `_AXIS = "A2"`,
  `_KIND = "replay"` (`verify/turn.py:69–70`) — the **same pair** the replayed path emits
  (`replay/report.py:117`). Not a discriminator.
- ❌ *Discriminate on `len(sub_verdicts)`.* The non-replayed branch emits exactly one
  (`turn.py:200`) and the replayed branch two or more, but that is incidental, not contractual.
- ⚠️ *Keep inferring from `cause`.* `_replayed_cause`'s own docstring says the cause is now
  *"a stable LABEL on both paths and **a consumer never has to know which path produced
  it**"* — the branch **deliberately unified** the namespace. Inference is exactly what it
  tells consumers not to do.

**Two viable options — this is the plan's one real judgment call, so checkpoint here:**

- **(A) Preferred — make it explicit.** Add `replayed: bool` to `TurnVerdict`; set `False` on
  the non-REPLAYED return (`turn.py:196–202`), `True` on the replayed return (`:267–274`).
  `attach.py` reads it directly. No inference anywhere, and the next consumer cannot repeat
  this mistake. **Cost:** `TurnVerdict` is persisted into corpus cases — check
  `src/belay/corpus/case.py` serialization and add the field optional-with-default, matching
  the `CASE_SCHEMA_VERSION` pattern already there. If that ripples further than one file,
  fall back to (B).
- **(B) Fallback — closed named vocabulary.** Import the four `REPLAYED_*` constants from
  `belay.replay.report` and treat membership as "this replayed". They are named, exported
  constants forming a closed set, not string sniffing. **Cost:** interop now depends on the
  cause vocabulary staying closed; add a test asserting the four constants are exactly the
  replayed-bucket set, so adding a fifth breaks loudly.

**Also required either way:** rewrite the `attach.py:25–33` and `:134–138` comments. They
currently assert a premise that is false on the merged tree; leaving them is worse than
having no comment.

**Validation:**
```bash
uv run pytest tests/test_interop_attach.py -q   # Phase 2 test now passes
uv run pytest -q                                # whole suite green
```

**Commit:** `fix(interop): derive unrestorable-pre-state from the real non-replayed branch`

## Testing strategy

- **Determinism is non-negotiable.** Every test here is offline and clock-free. The only real-
  data step (Phase 7.1) replays a **captured** trace — deterministic by construction. No model
  call anywhere in this PR; no fresh mint.
- **Never assert through the stub seam for 2a.** Restated because it is the single way this PR
  fails quietly: a stubbed test is green against the bug.
- **Regression surface:** the full suite must stay ≥754 passing. Any drop is a real regression,
  not a re-baseline.

## Edge cases → verdict

| Case | Result |
|---|---|
| Turn replayed, reduced UNVERIFIED, named `REPLAYED_*` cause | span cause = that cause; **never** `unrestorable-pre-state` |
| Pre-state genuinely unrestorable | `UNVERIFIED` + `unrestorable-pre-state` (unchanged) |
| Turn PASSes with a `NOT_COVERED` network sub-verdict | `PASS` **with** its coverage line, on every surface |
| Span matches no turn / ambiguous | `UNVERIFIED` + its existing named cause (unchanged) |
| Every sub-verdict `NOT_COVERED` | `UNVERIFIED` — never `NOT_COVERED`, never `PASS` (existing guard) |
| `readOnlyHint` violated + `openWorldHint: false` | `FAIL` — never softened (existing guard) |
