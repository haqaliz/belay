## 0. Decisions resolved before coding

**D1 — `NOT_COVERED` is sub-verdict-only, enforced inside `reduce`.**
```python
def reduce(verdicts):
    scored = [v for v in verdicts if v.status is not Status.NOT_COVERED]
    if not scored:
        return Status.UNVERIFIED          # NOT the new status
    return max(scored, key=lambda v: _RANK[v.status]).status
```
Not a losing rank value (`reduce([NOT_COVERED])` would then return it — the false-PASS shape),
and not per-call-site filtering (there is already one forgotten mirror, `cli.py:630`). Keeping
the empty case as `UNVERIFIED` preserves `test_empty_is_unverified_not_pass` and means the new
status can never reach `reduced_status` — which is what keeps `corpus/metrics.py`,
`corpus/case.py`, and `ledger.total_turns()` safe.

**D2 — `_RANK` still gains an entry** (or `reduce` asserts), so nothing `KeyError`s if a future
caller bypasses the filter. `cli.py:_worst` gets the same filter *and* the same entry.

**D3 — the coverage statement is a ledger field.** `phase0 report` re-renders stored JSON only.
Per the PRD's open question: **per-instance**, since `phase0 report` renders per-instance rows
and a per-run aggregate can be derived from per-instance data but not vice versa.

**D4 — the message keeps the promise distinction.** `NOT_COVERED` for declared-false must still
say the tool *declared* `openWorldHint: false` and that Belay does not observe egress. The
status changes; the sentence that answers the counter-argument does not.

**D5 — not-declared / declared-true keep returning `None`.** Deferred per the PRD.

## Edge cases → status

| Case | Result |
|---|---|
| `openWorldHint: false`, clean replay | **PASS** + `NOT_COVERED` network sub-verdict + coverage line |
| `openWorldHint: false` + `readOnlyHint: true` violated | **FAIL** (never softened) |
| Only `NOT_COVERED` sub-verdicts | **UNVERIFIED** (never `NOT_COVERED`, never PASS) |
| Un-annotated / `openWorldHint: true` | unchanged — no network sub-verdict |
| Unrestorable pre-state | **UNVERIFIED** with its named cause (unchanged) |
