- **Goal:** the additive `approval` section on `belay verify --json`.
- **Files:** the verify JSON builder; `tests/test_approval_verify.py` (new).

  1. a trace with 1 hold + 1 deny (`APPROVAL_TIMEOUT`) → the section reads

## Edge cases & error handling

- A trace whose hold record has no decision (cut mid-hold) reports the hold with no
  decision key — the report states what the trace states; never a fabricated cause.
- The section is derived, never stored: verify recomputes it from the trace each
  run (deterministic, no state).
