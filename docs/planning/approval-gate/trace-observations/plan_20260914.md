## Edge cases & error handling

- A decision record without a preceding hold record in the same trace: the reader
  reports it as-is (the reader reports, never repairs — a missing hold is the
  trace's statement; repair would fabricate).
- The kinds never enter the request index (`_record_frame`'s park path,
  `trace.py:382-428`): they are written via `record`, so `_await_request` never
  waits on them — pinned by the trace-ordering suite staying green untouched.
