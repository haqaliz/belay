## Edge cases & error handling

- Garbage frames never raise (the hook runs on every c2s frame — a raise would kill
  the direction via `_run`'s catch; still, never hold on doubt).
- Batch frames are never held — documented in the module docstring.
- `triggers_for` accepts a dict of `{annotation: {"state": tri-state}}` (the
  annotations.py shape) and tolerates missing keys.
