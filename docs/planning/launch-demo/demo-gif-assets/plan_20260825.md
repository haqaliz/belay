## 4. Testing strategy

- The generator is manual-marked by design (browser, operator machine) — its
  deterministic steps are the reproducibility mechanism (fixed waits over a static
  capture).
- Docs corrections verified by grep; console suite stays green.

## 5. Environment & determinism

- The gif is deterministic: static capture + fixed waits; no live timing.
- The browser install is an operator-machine step, documented in the script's error
  message.

## 6. Edge cases & error handling

- **No Playwright browser:** clear error, exit non-zero — never a partial gif.
- **The capture's flag turn is 0 or the diff is long:** the script's viewport/steps
  are tuned once by the operator; the alt text states the real numbers regardless.
- **gifenc memory on long sequences:** keep the sequence ≤ ~30 frames; the script
  asserts the frame count.
