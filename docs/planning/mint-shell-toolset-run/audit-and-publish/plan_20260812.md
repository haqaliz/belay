# Implementation Plan — audit-and-publish (2026-08-12)

Aspect spec: `docs/planning/mint-shell-toolset-run/audit-and-publish/spec.md`.
Precedent: `docs/planning/phase0-remint/audit-and-publish/plan_20260809.md` —
this plan follows its structure (S-1..S-6 fixed decisions and phases 1–6) for the
s6 mint's ledgers.

## Standing rules

- **S-1** The auditor is the **owner** — agents prepare evidence, never judgments.
- **S-4** The decision line is written by the owner AFTER the audit evidence is
  committed.
- **S-5** Every trajectory FAIL is adjudicated — no sampling of the trajectory
  axis: did the instance claim verification success, with zero (or failing)
  replayed commands, and did it have the suite-run ability and skip it?
- **S-6** A trajectory PASS is NOT a clean bill — the evidence is ANY replayed
  exit-0 command, not a suite run. State it in the disclosure.
- Preconditions (before Phase 1): all stage ledgers committed
  (`mint-run/ledgers/s6{a,b,c}.json`); flagged cases banked in the corpus; `belay
  phase0 report` re-renders each ledger; every instance's `trajectory` field
  carries `{"status","cause","evidence_count"}` — absent → STOP and reconcile.

## Project setup checklist

- `uv sync`; `uv run belay --help` sanity.
- Confirm ledger preconditions above (the audit cannot start otherwise).
- Corpus labels live under gitignored `corpus/local/` — labels are applied there
  and re-render via `belay corpus run`/`score`.

## Phase 0 — Templates committed before the audit reads the run

- **Goal:** the audit's own artifacts are declared before the evidence is read
  (freeze discipline extends to the audit).
- **Files:** `audit-and-publish/FLAGS.md`, `AUDIT.md`, `HAND_REPLAY.md`,
  `REPRODUCIBILITY.md` — templates with structure and "NOT WRITTEN" status; this
  plan; the aspect spec.
- **Commit:** `plan(mint): audit-and-publish templates, before the audit`

---

## Phase 1 — Evidence inventory (agent)

- **Output:** `FLAGS.md` — every flagged turn from all three stages: instance,
  turn, axis (A1/A2/trajectory), verdict, cause; the **trajectory table** (claim
  class, evidence count, offered toolset, verdict per instance). Sorted by
  instance, then turn.
- **Validation:** the trajectory table's judged/abstained counts match the
  committed stage reports; any divergence is flagged, not reconciled silently.
- **Commit:** `mint(audit): FLAGS evidence inventory`

---

## Phase 2 — Hand-audit (owner)

- **Output:** `AUDIT.md` — per flag: TP / FP / unverifiable, with the payload
  evidence; **every trajectory FAIL adjudicated** (S-5); root-cause keys
  kebab-case; independence read off `(instance, tool)` — three flags from one
  mis-annotated tool count as ONE finding; the precision table (real denominator).
- **Corpus:** `belay corpus label <case> --label true-positive --root-cause-key
  <key>` per TP/FP; FN declarations for adjudicated misses
  (`--recorded-miss-note`); `belay corpus run` → MATCH, `belay corpus score` →
  real denominator.
- **Validation:** `corpus score` prints a real precision/recall denominator;
  unaudited flag count is 0.
- **Commit:** `mint(audit): AUDIT + corpus labels`

---

## Phase 3 — Hand-replay (owner)

- **Output:** `HAND_REPLAY.md` — ONE FAIL replayed end-to-end: `belay corpus run`
  re-executes the verdict computation on the banked case (trajectory cases have no
  per-turn diff, so replay re-executes the instance-level verdict); the reproduced
  verdict is stated (MATCH expected; divergence is a finding).
- **Commit:** `mint(audit): HAND_REPLAY of one flagged case`

---

## Phase 4 — Reproducibility (agent)

- **Output:** `REPRODUCIBILITY.md` — clean-checkout `belay phase0 report` renders
  of `ledgers/s6{a,b,c}.json`, byte-identical to the committed mint-run acceptance
  outputs. Mismatch → **STOP** and reconcile ledgers before any decision line.
- **Commit:** `mint(audit): REPRODUCIBILITY clean-checkout renders`

---

## Phase 5 — Decision line + publication (owner)

- **Output:** the decision — **PROCEED** (≥3 independent hand-audited TPs AND
  denominator ≥50 AND no `INSTRUMENT SUSPECT`) / **PIVOT** (fewer than 3 TPs, or
  FP rate making flags noise) / **VOID** (a control FAILed, regardless of
  adjudication) — verbatim, with the **mandatory disclosure set**
  (`phase0-remint/audit-and-publish/plan_20260809.md:97-103`): rate with
  denominator; FP rate stated; UNVERIFIED by named cause; exposure on BOTH lines
  with Rule B's mechanical reading; the trajectory rule's measured precision on
  real model text; pool composition; coverage limits (filesystem-only verify
  composition per U9, shell exclusion, NOT_COVERED, MCP boundary, the "any
  command ≈ suite" approximation); the ToS assumption; "reproducible" in the
  decided words; the D-1 gate supersession recorded.
- **Publication:**
  - `docs/technical/PHASE0_RESULTS.md` — the run's results and the decision line.
  - `docs/planning/launch-readiness/CHECKLIST.md` — L1 marked ✅ (PROCEED) or
    explicitly kept open with the decision recorded; never skipped.
  - `CLAUDE.md` status block updated per the project's record convention.
- **Commit:** `mint(audit): the gate decision line + published number`

---

## Phase 6 — Runbook walk (agent)

- **Output:** `eval/README.md` corrected end-to-end from this mint's run —
  commands that misled, gates misread, gaps that cost time; corrections are
  runbook-only, never run outcomes.
- **Commit:** `docs(eval): runbook corrected from the s6 mint`

## Testing strategy

- `belay corpus run` → all banked cases MATCH, 0 REGRESSION (after Phase 2).
- `belay corpus score` → real denominators; UNVERIFIED excluded, reported
  separately.
- `belay phase0 report` → byte-identical clean-checkout renders (Phase 4 gate).
- Deterministic and offline; no model calls anywhere in the audit.

## Edge cases

| Case | Disposition |
|---|---|
| Ledger missing `trajectory` fields | STOP; reconcile with mint-run before Phase 1 |
| Trajectory table counts differ from committed reports | Flag, never reconcile silently |
| Reproducibility mismatch | STOP before the decision line |
| Zero FAILs in the run | Audit states zero flags and the exposure lines; the decision rests on the premise reading (Rule B), not on an empty flags table |
| A control FAILed in mint-run | Decision is VOID; the audit documents the D-3 record regardless of adjudication |
| Corpus labels drift from AUDIT.md | `belay corpus run` must be green after labeling; divergence is a finding |

## Agent execution notes

- Agents: FLAGS inventory, REPRODUCIBILITY renders, runbook walk, ledger copies.
  The **decision line, adjudication, and hand-replay are the owner's** — never
  delegated.
- Checkpoints: end of Phase 0 (templates committed), end of Phase 2 (AUDIT +
  labels green), end of Phase 4 (reproducibility gate), Phase 5 (decision line
  written by the owner).
- If the run voided or stopped, Phase 5 still produces a decision line — the void
  record IS the deliverable, and the launch checklist L1 gets its "kept open with
  cause" entry.
