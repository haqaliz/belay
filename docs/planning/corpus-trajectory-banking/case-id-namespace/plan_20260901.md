## 6. Edge cases & error handling

- **Rerun idempotence:** same trace, same corpus → `CaseExistsError` for both shapes,
  bucketed, instance disposition and denominator untouched (existing pins cover; the Phase-1
  extension adds byte-identity + label survival).
- **Unrestorable pre-state:** checked BEFORE the collision (deliberate ordering) — covered
  by aspect 2's negative test; nothing here changes it.
- **Doubled suffix:** a trace stem already ending in `-trajectory` yields
  `-trajectory-trajectory` — harmless, deterministic, not special-cased (documented in the
  PRD risks).
- **`_resolve_server_command`:** untouched — the trajectory case still stores the final
  turn's resolved command (`runner.py:486-488`).
