# Plan — shared corpus pattern catalog (issue #58)

Strict TDD. Branch `feat/58/aliz`.

## Task 1 — the whitelist and the bundle (RED → GREEN)

`src/belay/corpus/share.py` (pure, stdlib only):

- `pattern_of(case: Case) -> dict` — whitelisted facts only, per the PRD;
- `pattern_id(pattern) -> str` — sha256 of `json.dumps(pattern, sort_keys=True)`, prefixed
  `sha256:`;
- `build_bundle(cases) -> dict` — `{"schema": "belay-corpus-patterns/1", "patterns": [...]}`,
  sorted by id, deduped;
- `parse_bundle(raw) -> list[dict]` — fail-closed: non-object, wrong/absent schema, patterns
  not a list, an entry missing/misstyped a whitelisted key, an unknown extra key, a bad
  label/status → named `ValueError`.

Tests: exact key set; no path/trace/server/cause substring in the serialized bundle; id
stability and label sensitivity; dedupe; parse refusals.

## Task 2 — storage and the three commands (RED → GREEN)

`src/belay/corpus/share.py`:
- `load_patterns(corpus_dir) -> list[dict]` (`<dir>/patterns.json`, missing → `[]`);
- `save_patterns(corpus_dir, patterns)` — deterministic (`indent=2, sort_keys=True`) +
  atomic temp/rename;
- `merge_patterns(existing, new) -> list[dict]` — dedupe by id, sort by id.

`cli.py`: `corpus share export|import|list`, `--corpus-dir` consistent with the other corpus
commands, `--out`, `--json` on `list`. Exit 2 on any refusal; export of an empty corpus is a
valid empty bundle.

Tests: CLI round-trip, idempotent import, deterministic file bytes, malformed bundle exit 2,
`share list` text and `--json`, `patterns.json` does not affect `corpus list/run/score`.

## Task 3 — docs

README corpus section, `docs/STATUS.md` v-next, `CHANGELOG.md` Unreleased, the roadmap
Phase 2 line and `CAPABILITY_ROADMAP.md` C6 note, module docstrings. State plainly: patterns
are not cases, are never replayed, and are never scored.

## Task 4 — verification

`uv run pytest tests/test_corpus_share.py tests/test_corpus_*.py tests/test_cli_flag_parity.py -q`,
