## 1 · Design decisions (settled — do not re-litigate mid-build)

1. **The probe reuses `client.replay_turn`, it does not build new sandbox code.**
   `src/belay/replay/client.py:341` already takes `frames: Sequence[bytes]`, a
   `snapshot_manifest`, a `network` policy, a `timeout` and a `source_root` for relocation.
   The probe calls it with the **same** resolved argv, the **same** manifest and
   `frames=[initialize, tools/list]`. Nothing about the sandbox, restore or relocation is
   reimplemented.
2. **The probe never enters the replayed conversation.** It is a separate call with its own
   restore and its own spawn. The recorded frames are untouched — this is what keeps AC-6
   (byte-identical no-op) reachable.
3. **Resolution is exported, never copied.** `WORKSPACE_PLACEHOLDER` substitution lives
   privately at `src/belay/replay/engine.py:508-521` and is never returned. Extract it to one
   shared function used by both the replay and the probe.
4. **`tool_offered: Optional[bool]`** is the seam threaded into scoring.
   `True` -> today's behavior exactly. `False` -> abstain. `None` -> abstain with a
   **distinct** probe-failure reason. **Absence of evidence is never evidence of absence.**
5. **A1 owns status + message. A2 (`cause-and-surfaces`) owns kind, bucket and rendering.**
   A1's tests assert `Status.UNVERIFIED` and message content; they must **not** assert bucket
   labels, which do not exist yet.
6. **Order:** probe runs on DIVERGED **before** `classify_determinism`.

## 2 · Phases

Each phase is RED -> GREEN -> REFACTOR and leaves the suite green.

### Phase 1 — RED: the anti-overreach guard, written FIRST

- **Goal:** pin that A2 keeps its teeth, *before* any abstention path exists. This is the
  guard against the single most dangerous outcome (gutting A2). Writing it first is
  deliberate.
- **Files:** `tests/test_verify_tool_not_offered.py` (new).
- **Tests:** AC-2 — a genuine deterministic divergence on a tool the boundary **does** offer
  still FAILs, unchanged, for two shapes: (a) a value mismatch; (b) recorded success vs
  replayed `isError: true` **where the tool is offered**. Model on
  `tests/test_verify_dual_server.py`; darwin-gate the real-replay ones with the existing
  named cause `replay-reinvokes-seatbelt`.
- **Validation:** these tests must be **GREEN against today's code** — they describe existing
  behavior. A red result here means the test is wrong, not the engine.
- **Commit:** `test(verify): pin that a real deterministic divergence still FAILs`

### Phase 2 — Export the argv resolution

- **Goal:** one substitution site, reachable by both replay and probe.
- **Prereq:** Phase 1.
- **Files:** `src/belay/replay/engine.py` (extract), `tests/test_replay_resolution.py` (new).
- **Work:** extract the `WORKSPACE_PLACEHOLDER` logic (`engine.py:508-521`) into an exported
  helper — e.g. `resolve_server_argv(server_command, source_root) -> list[str]` — preserving
  the existing rootless behavior exactly (a `{workspace}` token with `source_root is None`
  still yields the `ROOTLESS_RELOCATION` outcome; the helper must not swallow it).
  `engine.replay_turn` then **calls the helper** rather than inlining.
- **Tests:** AC-7 — identical resolution for both callers; a guard that the placeholder
  string is substituted in exactly one place.
- **Validation:** `uv run pytest tests/ -k "replay or relocation" -q` — no behavior change.
- **Commit:** `refactor(replay): export argv resolution so one substitution site serves both`

### Phase 3 — The probe

- **Goal:** ask the boundary what it offers; return a three-way answer.
- **Prereq:** Phase 2.
- **Files:** `src/belay/replay/probe.py` (new), `tests/test_replay_probe.py` (new).
- **Work:** `offered_tools(argv, *, snapshot_manifest, source_root, network, timeout)` builds
  MCP `initialize` + `tools/list` frames, calls `client.replay_turn`, parses the reply, and
  returns the set of offered tool names — or **`None`** when the probe could not run or its
  reply could not be read (spawn failure, timeout, unparseable, missing `result.tools`).
  **It must never raise into the verdict path** and must never return an empty set to mean
  "could not read".
- **Tests:** offered / not-offered / unparseable / spawn-failure / timeout, using existing
  fixture servers (`tests/fixtures/filesystem_server.py`, `shell_command_server.py`,
  `dies_midway_server.py`) plus a new fixture omitting a tool. Real-spawn tests darwin-gated;
  the parsing logic tested platform-independently.
- **Validation:** `uv run pytest tests/test_replay_probe.py -q`
- **Commit:** `feat(replay): a tools/list probe that asks the boundary what it offers`

### Phase 4 — Wire into `verify_turn` and gate result-equivalence

- **Goal:** the false FAIL becomes an honest abstention.
- **Prereq:** Phase 3.
- **Files:** `src/belay/verify/turn.py`, `src/belay/verify/result.py`,
  `tests/test_verify_tool_not_offered.py` (extend).
- **Work:**
  - `verify_turn`: on `reply.result_equivalence == DIVERGED`, call the probe with the
    **resolved** argv (Phase 2 helper) **before** `classify_determinism`; compute
    `tool_offered`. When `tool_offered is not True`, **skip `classify_determinism` entirely**.
  - `render_result_verdict(reply, determinism, *, tool_offered=None)`: in
    `_deterministic_divergence_verdict` (`result.py:170-209`), add the third shape ahead of
    the final FAIL — the docstring already frames it as *"FAIL is the strong claim and only
    one shape earns it"*; extend that reasoning rather than bolting on.
  - Ambiguity (2+ configured servers offering the tool) abstains — note that with only
    `--server` + `--shell-server` configured, this is reachable but rare; still fail-closed.
- **Tests:** AC-1 (the PRD's live repro as a regression test), AC-4 (probe failure distinct,
  never "not offered", never FAIL), AC-5 (ambiguity), AC-9 (`classify_determinism` **not**
  called on a not-offered turn — assert via spy/seam, do not assume).
- **Validation:** `uv run pytest tests/ -k "verify or result" -q`; then reproduce the PRD
  repro by hand and confirm `UNVERIFIED: 1, FAIL: 0`.
- **Commit:** `fix(verify): a tool the boundary never offered is UNVERIFIED, never a FAIL`

### Phase 5 — Gate effect-conformance

- **Goal:** kill the second fabricated sub-verdict (review finding 1, reproduced).
- **Prereq:** Phase 4.
- **Files:** `src/belay/verify/effect.py`, `src/belay/verify/turn.py`, tests (extend).
- **Work:** `render_effect_verdict(..., *, tool_offered=None)` abstains instead of emitting
  *"the observed effect conforms"* when the boundary never offered the tool. The declared
  annotation is read from the trace and is **not** evidence that anything executed.
- **Tests:** AC-3 — on a not-offered turn no sub-verdict says the observed effect conforms;
  both A2 sub-verdicts abstain. Assert the exact string cannot appear.
- **Commit:** `fix(verify): effect-conformance abstains when the boundary never offered the tool`

### Phase 6 — Regression, invariants, cost

- **Goal:** prove nothing else moved.
- **Files:** tests (extend).
- **Tests:**
  - **AC-6** a fully-offered trace produces byte-identical output to today (capture a
    pre-change baseline in Phase 1 and diff).
  - **AC-8** `replayed_is_error` unchanged on a not-offered turn, **and** an instance-level
    trajectory verdict over such turns is identical before/after — mirroring
    `trajectory-toolset-rescope`'s false-abstention invariant.
  - Full suite: `uv run pytest -q`.
  - **Measure and record** the probe's added wall-clock on a would-be-FAIL turn, and the
    saving from skipping `classify_determinism`. Report the measurement; do not assert a
    predicted number.
- **Commit:** `test(verify): the probe moves no other verdict, and the trajectory axis cannot see it`

## 4 · Testing strategy

- **Lifted from the aspect spec's AC list**, not invented in parallel.
- **AC-2 is written FIRST and must be green against today's code** — it is the guard, and a
  guard written after the change it guards is not a guard.
- Fixture MCP servers only; **no network**, no clock dependence, no random ordering.
- **Platform gating:** real re-execution -> `@darwin_only` with the existing named cause
  `replay-reinvokes-seatbelt` (`tests/test_verify_dual_server.py:86-89`), which
  `tests/test_platform_gate_named_causes.py` machine-checks. Parsing/resolution/three-way
  logic must run on **both** platforms via non-replay seams, as
  `test_verify_dual_server.py` tests 3-5 do.
- Commands: `uv run pytest tests/test_verify_tool_not_offered.py -q`, then
  `uv run pytest -q` before the aspect is called done.

## 5 · Edge cases -> verdicts (a silent pass is never acceptable)

| Condition | Verdict |
|---|---|
| Tool offered, replies diverge deterministically | **FAIL** — unchanged (AC-2) |
| Tool offered by none of the configured servers | **UNVERIFIED**, cause: boundary does not offer the tool |
| Tool offered by 2+ configured servers | **UNVERIFIED**, cause: ambiguous |
| Probe spawn fails / times out / reply unparseable | **UNVERIFIED**, cause: probe could not decide — **distinct**, never "not offered" |
| `{workspace}` present but no `source_root` | existing `ROOTLESS_RELOCATION` UNVERIFIED — unchanged; the probe must not mask it |
| Reply parses but has no `result.tools` | probe returns `None` -> probe-failure abstention, never an empty offered-set |
| Non-DIVERGED reply | probe never runs; path byte-identical (AC-6) |

## 6 · Determinism & auditability

- No clock, no network, no random ordering anywhere in this aspect.
- The probe restores the **turn's own snapshot** into a fresh scratch, so it asks the *same
  boundary the replay used* — not a differently-rooted spawn.
- **No cross-turn cache in v1** (PRD M3b): keying on the operator-typed template would let
  one trace's answer decide another's under `phase0 run`, which processes a whole directory.

## 7 · Agent execution notes

- **Checkpoint after Phase 1** — human review of the anti-overreach tests before any
  abstention path is written. If those tests are weak, everything after them is unguarded.
- **Checkpoint after Phase 4** — re-run the PRD's live repro by hand and paste verbatim
  output into the PR. That command is the aspect's proof.
- **Likely to need iteration:** building well-formed `initialize` + `tools/list` frames the
  fixture servers accept; and the ambiguity path, which is reachable but rare today.
- **Ask before proceeding if:** the probe cannot be made to reuse `client.replay_turn`
  cleanly — that would mean duplicating sandbox/restore logic, which this plan forbids, and
  the design should be revisited rather than worked around.
- **Do not** touch cause bucket labels, `_PREFIX_LABELS`, `_REPLAYED_CAUSES` or any rendering
  surface here — that is aspect `cause-and-surfaces`, and splitting it keeps both diffs
  reviewable.
