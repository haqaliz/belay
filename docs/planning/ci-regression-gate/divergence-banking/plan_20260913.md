## Design decisions (pinned; deviate only with the integrator)

1. **Bank the new capture's REGRESSION turns, nothing else.** When `gate check` finds a
   regression, each divergent turn of the **new capture** whose transition was
   PASS/WARN → FAIL (the decision table's regression rows, `src/belay/gate/compare.py`)
   banks as a corpus case via the existing `add_case` (`src/belay/corpus/add.py:280`):
   - `records`: the new capture's read records; `target_turn_index`: the turn ordinal.
   - `verdict`: the recomputed `TurnVerdict` (status FAIL) — **`check_gate` must retain
     the per-turn `TurnVerdict` objects** (aspect 3's composition currently serializes
     them; keep the objects for the ingest step).
   - `server_command`: the STORED policy's command, resolved per turn by the phase0 rule
     (`_resolve_server_command(tool_name, server_command, shell_server_command)`,
     `src/belay/phase0/runner.py:104-122`) — the case stores what the turn actually
     replayed against.
   - `invariants`: the baseline's STORED invariants (the case recomputes under the same
     policy → MATCH, the stored-invariants pin); `replays`/`timeout`: stored.
   - `human_label` defaults `"pending"` — the engine never labels its own cases.
   - `source_trace_id`: the new trace's stem; `captured_at`: the check time (the CLI
     boundary reads the clock, mirroring `phase0 run`'s injection at
     `src/belay/phase0/runner.py:61`).
   - Case id = `{new-trace-stem}-turnN` — the standard per-turn namespace; a fresh
     capture's stem is unique, so no collision with the baseline or other runs.
2. **Default-on with `--no-ingest`.** Banking is default; `--no-ingest` disables it
   (parity with `phase0 run`'s opt-out). The gate's verdict/exit code is computed
   BEFORE and independently of ingest; ingest never changes it.
3. **Ingest failure is error-contained.** Per-turn `ValueError` (e.g. `CaseExistsError` on
   a re-banked regression) is caught, reported on the gate surface with a named message,
   and the gate's exit code is unchanged — mirror `_verify_one_trace`'s per-turn ingest
   handling (`src/belay/phase0/runner.py:455-470`).
4. **Clean checks bank nothing.** Ingest runs only when a regression row exists.
5. **CLI additions to `gate check`:** `--corpus-dir` (default `corpus/local/`, the corpus
   convention) and `--no-ingest`. Both declared in `tests/test_cli_flag_parity.py`
   (`--no-ingest` is shared with `phase0 run` — the parity guard's discovery test
   requires it; `--corpus-dir` shared with the corpus commands).
6. **MATCH recompute needs fidelity.** A banked case recomputes MATCH through
   `belay corpus run` only when the case's stored pre-state restores — a snapshot-bearing
   capture, so the full roundtrip test is darwin-gated with a named cause (the corpus
   roundtrip precedent). Banking mechanics (case created, expected FAIL stored, pending
   label, `--no-ingest`, id collision) run everywhere with snapshot-less captures.

## Testing strategy

- Mechanics (everywhere): banking, `--no-ingest`, clean-banks-nothing, collision
  containment, stored-policy fidelity.
- Fidelity (darwin-gated, named cause): banked case recomputes MATCH through
  `belay corpus run`.
- Compatibility: parity guard, corpus suites untouched.

## Environment & secrets

`BELAY_CORPUS_DIR`-style env if `corpus add` honors one — check and mirror; otherwise the
flag default `corpus/local/` suffices. Cases hold trace + pre-state: as sensitive as the
trace itself; never uploaded.

## Edge cases & error handling

- Regression with zero bankable turns (every divergent turn's case already exists):
  ingest reports the collisions by name; exit still 1 (the regression is the signal).
- A snapshot-less new capture's regression turns bank with `absent` pre-state — the case
  is stored (the mechanics are real) but its recompute abstains UNVERIFIED; only
  snapshot-bearing captures recompute MATCH. Documented, never silent.
- `--no-ingest` + `--json`: the ingest section is omitted entirely (absent-never-zero).
