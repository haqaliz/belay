## 4. Edge cases & error handling

- `--no-claim-axis` + `--claim-author` both given → flag wins (axis disabled); asserted.
- `--claim-author` un-lexable → exit 2 fail-closed (`cli.py:654-667` pattern).
- Author configured but trace has no claim → A3 UNVERIFIED `NO_CLAIM_RECORDED` on the instance
  line — never a fabricated clean.
- `corpus run --no-claim-axis` on a corpus with claim cases: all other cases unaffected
  (byte-identical vs axis-on for non-claim cases) — asserted by the refutation test.
