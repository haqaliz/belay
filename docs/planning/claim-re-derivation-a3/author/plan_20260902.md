## 4. Edge cases & error handling

- Empty/whitespace `BELAY_CLAIM_AUTHOR` → None (absent), not a crash.
- Un-lexable command (unbalanced quotes) → None (absent), not a crash — mirrors the
  `--shell-server` un-lexable gate (`cli.py:654-667`).
- Author writes huge output → cap captured bytes (e.g. 1 MiB) to bound memory.
- Author hangs → timeout kills; None; message `NO_CHECK_AUTHOR` (the evaluator owns the cause).

## 5. Determinism

- The fake is deterministic; the contract is JSON-in/JSON-out; nothing network; no clock in
  assertions (timeout tests use a generous sleep bound, not timing assertions).
