## 2. Contracts (pinned)

- **Schema v5** (`case.py`): optional instance-level `claim` expected field, mirroring v4
  `trajectory` (`case.py:82-88`):
  `{"status": "FAIL"|"WARN"|"UNVERIFIED", "cause": str|null,
    "check": {"source": str, "exit_code": int|null}}` — all keys required when present;
  malformed → load error, never silent drop. `CASE_SCHEMA_VERSION = 5`. Omitted when unset
  (`_to_payload` pattern) — v1–v4 cases load unchanged.
- **Case id namespace**: `{trace}-claim` (disjoint from `-turnN` and `-trajectory`;
  `_safe_case_id`, `add.py:122-142`).
- **Shaping seam**: `claims.claim_case(...)` returns the v5 payload (mirrors
  `trajectory_case`, `invariants.py:732-772`); `add_case(..., claim=None)` passes it through
  verbatim, validated at load (`add.py:298-305` pattern).
- **Recompute routing** (`run.py`): `case.claim is not None` → `_recompute_claim_case` — the
  stored trace + manifests re-verified through `evaluate_claim` directly (no per-turn loop;
  A3 is instance-level). Divergence dimension named `claim status`. **Under
  `--no-claim-axis` (param `disable_claim_axis=True`): SKIP with named cause
  `CLAIM_AXIS_DISABLED` — never REGRESSION.**
- **Declared miss**: a v5 case may declare `recorded_miss` (v3 machinery unchanged); the
  miss-closing transition for the claim dimension is FAIL→PASS-equivalent — but A3 never
  emits PASS, so the only close is an A3 FAIL recomputing to… nothing (silence). Decide in
  Phase 3 with a test: silence-on-recompute of a declared miss ⇒ the miss is still open
  (STILL_MISSED) unless a sharpened check FAILs again (MISS_CLOSED requires FAIL). Do not
  invent a PASS close.

## 4. Edge cases & error handling

- A `claim` case whose stored trace lacks a claim record → recompute abstains
  `NO_CLAIM_RECORDED` → divergence vs expected FAIL → REGRESSION (honest: the case's own
  claim vanished — that IS a regression).
- `check` payload with `exit_code: null` (UNVERIFIED case) round-trips as null, absent-never-zero.
- Old corpus dirs (no `claim` key) unaffected; `corpus run` over a mixed corpus keeps
  per-turn/trajectory behavior byte-identical.
