## 2. API contract (pinned — later aspects build against this)

```python
# src/belay/verify/claims.py
CAUSE_NO_CLAIM_RECORDED      = "NO_CLAIM_RECORDED"
CAUSE_CLAIM_UNCLASSIFIABLE   = "CLAIM_UNCLASSIFIABLE"
CAUSE_NO_CHECK_AUTHOR        = "NO_CHECK_AUTHOR"            # author configured but returned no check
CAUSE_CHECK_DID_NOT_EXECUTE  = "CHECK_DID_NOT_EXECUTE"      # launch failure OR timeout (single cause;
                                                            # message names which)
CAUSE_FINAL_STATE_UNOBSERVABLE = "FINAL_STATE_UNOBSERVABLE"

@dataclass(frozen=True)
class Check:
    source: str                 # the check, verbatim — the artifact A3 surfaces
    argv: tuple[str, ...]       # how to run it, relative to the final workspace cwd

@dataclass(frozen=True)
class CheckResult:
    exit_code: int | None       # None = did not execute (launch failure or timeout)
    output: str
    error: str | None

class CheckAuthor(Protocol):
    def author_check(self, claim_text: str, *, classification: str,
                     turns: Sequence[TurnFact], final_state_files: Sequence[str]) -> Check | None: ...

class CheckRunner(Protocol):
    def run(self, check: Check, *, workspace: Path, timeout: float) -> CheckResult: ...

class ContainedRunner:  # the real runner — `contained(argv, workspace=workspace, network=deny)`,
                        # subprocess.Popen in the contained scope, stdout+stderr captured, timeout
                        # kills; launch error / timeout → CheckResult(exit_code=None, ...)

def evaluate_claim(*, records, skips, verdicts, author: CheckAuthor | None,
                   manifest_dir, server_command, shell_server_command=None,
                   timeout: float = CHECK_TIMEOUT, replays: int = 3,
                   workspace: Path | None = None) -> Verdict | None: ...
```

`evaluate_claim` returns:
- `None` when `author is None` (axis absent — caller renders the coverage note) or when the
  check exits 0 (silence, D3). **`None` is never PASS.**
- `Verdict(axis="A3", kind="claim", status=FAIL, observed=<exit_code>, expected="exit 0",
  message=<f"{check.source} · exit {code}">)` on non-zero exit.
- `Verdict(axis="A3", kind="claim", status=UNVERIFIED, ..., message=<named cause>)` per the table.

Decision table (each row a test — `evaluator/spec.md` In-scope):
| Condition | Result |
|---|---|
| `author is None` | None (absent) |
| no claim record (`extract_claim` → None) | UNVERIFIED `NO_CLAIM_RECORDED` |
| classification != VERIFICATION | UNVERIFIED `CLAIM_UNCLASSIFIABLE` (message names the shape) |
| final state unobservable (workspace param None and final-turn replay not REPLAYED) | UNVERIFIED `FINAL_STATE_UNOBSERVABLE` |
| author returns None / raises | UNVERIFIED `NO_CHECK_AUTHOR` |
| runner returns `exit_code=None` (launch failure / timeout) | UNVERIFIED `CHECK_DID_NOT_EXECUTE` (message: "timed out after Ns" vs "could not launch") |
| exit non-zero | FAIL |
| exit 0 | None (silence) |

Final-state materialization: find the **last `tools/call` turn** (via the correlation index —
`belay.index.tool_calls`), `replay_turn(records, n, server_command=…, shell_server_command=…,
manifest_dir=…, timeout=…)`; REPLAYED → `workspace` is the final state, `scan_tree` → the file
list given to the author. `workspace=` param short-circuits (test seam; surfaces may pass it
later — follow-on optimization, not v0). Never touches live state or the original trace.

## 4. Edge cases & error handling

- Final turn is a `run_process` → shell-server routing must be honored (pass
  `shell_server_command` through, like `verify_turn` `turn.py:363-368`).
- Claim seq after the last turn (claim is a session record, seq 21 vs turns ≤ 19 in the demo):
  fine — the claim is not a turn; only its classification gates.
- Empty workspace file list → author still called with `[]` (its choice); runner must not crash.
- `replay_turn` raises (substrate) → `FINAL_STATE_UNOBSERVABLE`, never a crash.
- Author raises → `NO_CHECK_AUTHOR`, never a crash.

## 5. Determinism

- Everything deterministic except the author — which is a seam; tests inject fakes. No network
  (runner is local subprocess; replay is local). No clock/random in assertions.
