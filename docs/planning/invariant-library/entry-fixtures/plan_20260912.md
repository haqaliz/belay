## Testing strategy

- All new tests darwin-gated (`replay-reinvokes-seatbelt`) because they
  re-invoke the seatbelt sandbox; pure-rule coverage already lives in aspect 1.
- Deterministic, no network (fake stdio servers, loopback-free).
- Banked cases live only in `tmp_path` corpora — `corpus/local/` is gitignored
  and never committed; the committed artifact is the fixture test itself.

## Environment & determinism

- Snapshot/restore uses the real sandbox (seatbelt) — the reason for the gate.
- No env vars; no external tools.

## Edge cases & error handling

- delete_server's pre-state must contain the file it deletes (snapshot the
  workspace with `docs/todo.txt` present); if the pre-state lacks it the turn
  replays a no-op and A1 would PASS — that is the false-PASS the guard test
  exists to prevent.
- Recompute must use the case's stored invariants (PRD gap 1) — read
  `corpus/run.py` to confirm, pin the behavior, never re-resolve names.
- Egress turns are UNVERIFIED with named cause — never PASS, never FAIL.
