### Phase 1.2 — Evaluation branches (byte-prefix, rule-generic messages)

- **Goal:** `evaluate_invariant` decides both rules from the BTH-1 `FieldDiff`
  with byte-prefix scope semantics; FAIL names the rule and the violating path(s);
  `delta is None` → UNVERIFIED, never PASS.
- **Prerequisites:** Phase 1.1.
- **RED (write first):** in `tests/test_invariant_delta_rules.py`, pure fixtures
  using real trees + `diff_records(scan_tree(pre), scan_tree(post))` (house
  pattern `tests/test_inferred_invariants.py:93-106`; helper builds pre/post tree
  dirs under `tmp_path`):
  - `no-create`, scope `b"scratch/"`: pre has no `scratch/x.txt`, post has it →
    **FAIL** whose message names the rule `no-create` and the path; the verdict is
    an `A1` `invariant` sub-verdict shape (assert kind/axis/status).
  - `no-delete`, scope `b"scratch/"`: pre has `scratch/x.txt`, post lacks it →
    **FAIL** naming `no-delete` and the path.
  - clean delta (a modified file only, e.g. content change under scope) → **PASS**
    for both rules (they judge presence, not content).
  - creation/deletion **outside** the scope → PASS.
  - near-miss prefix: scope `b"tests/"`, created `testsuite/x.txt` → PASS (the
    read-only near-miss pin, `tests/test_invariant_weakening_rule.py:222-251`,
    reproduced for the new rules).
  - empty scope `b""` → whole-tree semantics: any created/deleted path fires.
  - `delta=None` → UNVERIFIED with a named cause, never PASS (mirror
    `tests/test_invariant_eval.py`'s delta-None pin).
- **GREEN:** edit `evaluate_invariant` in `src/belay/verify/invariants.py`
  (line ~233-325):
  - factor the read-only branch's byte-prefix walk so the rule name in FAIL/PASS
    messages comes from the invariant — **verify which tests pin the read-only
    FAIL/PASS message text first** (grep tests for `read-only` message asserts;
    `tests/test_invariant_weakening_rule.py` and `tests/test_invariant_eval.py`
    are the likely homes) and keep read-only's rendered message byte-identical
    where pinned; if nothing pins it, a rule-generic message
    (`A1 invariant '<rule>' violated ...: <paths>`) is acceptable;
  - add the created/deleted predicates from `FieldDiff` (`field is None and left
    is None` = created; `field is None and right is None` = deleted — confirm
    against `src/belay/snapshot/bth1.py:174-185`), byte-prefix on `fd.path` like
    the read-only branch;
  - `delta is None` → existing UNVERIFIED cause path.
- **Validation:** `uv run pytest tests/test_invariant_delta_rules.py
  tests/test_invariant_eval.py tests/test_invariant_weakening_rule.py -q`
- **Commit:** `feat(invariants): evaluate no-create/no-delete from the delta`

## Edge cases & error handling

- Created/deleted detection must come from `FieldDiff` structure (`field is None`
  side markers), never from string heuristics.
- Empty scope = whole tree (mirror read-only).
- Near-miss prefixes must not fire (byte-prefix, not substring).
- `delta is None` → UNVERIFIED with existing named cause; never PASS.
- Message pin risk: check every test that asserts on the read-only FAIL/PASS
  message text before refactoring the message; keep read-only's text byte-identical
  where pinned.
