## Task 3 — composite Action (`action.yml` at repo root)

Inputs: `trace` (required), `run-id`, `server`, `strict-shape` (default `false`), `version`
(pip spec; empty = use `belay` on PATH). No outputs. Steps:

```bash
# install, only when version is non-empty
python -m pip install "$VERSION"

# gate check, flags before --server by construction
args=(gate check "$TRACE")
[ -n "$RUN_ID" ] && args+=(--run-id "$RUN_ID")
[ "$STRICT" = "true" ] && args+=(--strict-shape)
if [ -n "$SERVER" ]; then read -r -a srv <<< "$SERVER"; args+=(--server -- "${srv[@]}"); fi
belay "${args[@]}"
```

`server` is whitespace-split (documented). The baseline dir is CWD-relative
`baselines/local/` and stays gitignored; the workflow restores it.

New `tests/test_gate_action.py` (YAML-parsed, modeled on `test_release_workflow.py`):
