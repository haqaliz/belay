## 1. Implementation Phases

### Phase 1 — Collision is detected before any write

**Goal:** `add_case` refuses a re-add with a named error, having mutated nothing.
**Prerequisites:** none.

**RED (write these first, watch them fail):** in `tests/test_corpus_add.py`
- `test_readd_same_case_id_raises_case_exists` — second `add_case` raises `ValueError`, message
  contains the case id and the word `exists`. *(Fails today with `FileExistsError`.)*
- `test_readd_leaves_existing_case_byte_identical` — snapshot every file under the case dir
  (`trace.jsonl`, `manifest.json`, `case.json`, `prestate/**`, `task_prestate/**`) as
  `{relpath: sha256}` before the attempt; assert the map is unchanged after. *(Fails today at
  `trace.jsonl` — truncated at `add.py:272` before the raise at `:279`.)*
- `test_readd_preserves_human_label_and_root_cause` — label the case `true-positive` with a
  `root_cause` via `corpus.curate.set_label`, attempt re-add, assert `load_case` still reads
  `true-positive` and the same `root_cause`.
- `test_case_exists_error_is_a_valueerror` — `issubclass(CaseExistsError, ValueError)`. This is
  the load-bearing type contract: `runner.py:260` catches `ValueError`, and the whole
  denominator-safety property in Phase 2 rests on it.

**GREEN — `src/belay/corpus/add.py`:**
1. Define `class CaseExistsError(ValueError)` with a docstring stating *why* it subclasses
   `ValueError` (so `phase0/runner.py:260`'s existing handler routes a collision into
   `flagged_unaddable` rather than letting it reach `run_batch`'s catch-all and ERROR the whole
   instance). Add to `__all__`.
2. Insert the check **after** the existing pre-state/manifest validation (`add.py:253-264`) and
   **before** `case_dir.mkdir` (`:268`):
   ```python
   case_id = _safe_case_id(source_trace_id, target_turn_index)
   case_dir = Path(corpus_dir) / case_id
   if case_dir.exists():
       raise CaseExistsError(
           f"corpus case {case_id!r} already exists at {case_dir}; refusing to overwrite "
           f"(a stored case may carry a human label). Delete it or use a fresh corpus dir."
       )
   case_dir.mkdir(parents=True)      # exist_ok no longer needed, and must NOT be passed
   ```
3. **Ordering is deliberate and must be commented:** pre-state validation stays first so existing
   error messages and their tests are unchanged; a turn that both collides *and* lacks a
   pre-state keeps reporting the pre-state cause, exactly as today.
4. **Any** existing case dir counts as a collision — including one already half-damaged by the
   bug this aspect fixes. Conservative on purpose; the operator's remedy is explicit deletion.
   Say so in the docstring.
5. Drop `exist_ok=True` from the `mkdir`, so a future regression surfaces as an error rather
   than a silent overwrite.
6. Update the `add_case` docstring's `Raises:` paragraph (`:249-251`) to name the third case.

**Validation:** `uv run pytest tests/test_corpus_add.py -q` green; full suite green.
**Commit:** `corpus-collision-guard: a stored case is never overwritten, and never half-written`

### Phase 3 — `--no-ingest`, which hides nothing

**Goal:** a pure measurement writes no cases, and the report says so.
**Prerequisites:** Phase 1 (independent of Phase 2).

**RED — `tests/test_phase0_cli.py` + `tests/test_phase0_runner.py`:**
- `test_no_ingest_writes_no_case_dirs` — with the flag, the corpus dir stays empty (or absent);
  flagged turn counts and `turn_status_counts` are unchanged versus an ingesting run.
- `test_no_ingest_is_stated_in_the_report` — the rendered report contains an explicit
  ingestion-disabled line. **This is the honesty test:** with ingestion off, `flagged_addable` is
  empty for a reason that has nothing to do with addability, and an unlabelled empty list reads
  as "nothing could be added". The report must distinguish *not attempted* from *attempted and
  failed*.
- `test_no_ingest_does_not_populate_flagged_unaddable` — turns skipped by the flag must **not**
  appear as unaddable failures.

**GREEN:**
1. `src/belay/phase0/runner.py`: add keyword-only `ingest: bool = True` to `run_batch` and
   `_verify_one_trace`; when False, skip the ingest loop entirely (leaving both `flagged_addable`
   and `flagged_unaddable` empty) while still computing `flagged_turns` and the disposition.
   Default `True` keeps every existing caller and test byte-identical.
2. `src/belay/cli.py`: add `--no-ingest` to the `phase0 run` parser (near `--corpus-dir`,
   ~`:1798-1805`), pass `ingest=not args.no_ingest` into `run_batch`, and emit the
   ingestion-disabled line in the report block. Help text must say the flag suppresses corpus
   writes and **not** detection.

**Validation:** `uv run pytest tests/test_phase0_cli.py tests/test_phase0_runner.py -q`; full suite.
**Commit:** `corpus-collision-guard: --no-ingest measures without writing, and says so`

## 5. Edge Cases & Error Handling — and the verdict each produces

**Nothing in this aspect changes any verdict.** A collision changes *ingestion accounting* only.
That separation is the point: the corpus is where a finding is *stored*, never where it is
*decided*.

| Case | Behaviour | Verdict impact |
|---|---|---|
| Case dir exists, fully formed | `CaseExistsError`; turn → `flagged_unaddable` with cause | none — turn keeps its real `FAIL`; instance stays `VERIFIED_FLAGGED` and **stays in the denominator** |
| Case dir exists, half-written by the old bug | treated as a collision (conservative) | none; operator deletes explicitly |
| Turn has no restorable pre-state | existing `ValueError`, unchanged message | none — existing behaviour |
| Both: no pre-state **and** a colliding dir | pre-state error wins (ordering is deliberate) | none |
| `--no-ingest` | no case written; `flagged_addable`/`flagged_unaddable` both empty; report states it | none — detection unchanged |
| Corpus dir unwritable / disk full | `OSError` propagates → `run_batch` records `ERRORED` with the message | instance excluded from denominator, **visibly** as `ERRORED` — an honest failure, not a silent one |

**No silent pass anywhere.** A collision never becomes a stored case, never a PASS, and never an
invisible drop.
