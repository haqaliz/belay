## 2. Phases (TDD, commit per phase)

### Phase 1 — RED: `tests/test_triage_budget.py`

1. **Threshold:** a fixture score set (per-turn `TriageScore`), replay exactly the turns
   with score ≥ threshold; ties broken deterministically by turn index.
2. **Top-N:** replay exactly the N highest-score turns (deterministic tie-break by turn
   index, lowest index first).
3. **Union:** when both knobs are given, a turn is replayed if either rule spares it.
4. **Shadow mode:** no knobs ⇒ every turn replayed, every score recorded (the function
   returns all turns + the scores).
5. **All-abstain:** every triage call returned `None` ⇒ nothing is skipped (fail-open,
   full replay).
6. **Edge shapes:** empty turn list; N ≥ len(turns); threshold 0.0 / 1.0.
7. **Skip cause:** the constant exists and is registered — `canonical_cause` maps it to
   the `TRIAGE_SKIPPED_BY_BUDGET` label (the report surface renders it, never
   "unrestorable (no recorded cause)"); the guard test fails if a future edit drops the
   registration.
