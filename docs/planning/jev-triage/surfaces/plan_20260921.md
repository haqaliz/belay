## 2. Phases (TDD, commit per phase)

### Phase 1 — RED: `tests/test_verify_triage_surfaces.py`

1. Flags parse on `verify` only: `--triage-author` (one quoted string, shlex-split, exit
   2 on un-lexable — mirror `--claim-author` `cli.py:946-962`), `--triage-threshold FLOAT`,

   replay-bearing surface (the parity discovery test fails until registered — that is
   the RED for the guard half).
2. A skipped turn renders **UNVERIFIED with the TRIAGE cause** on text and `--json`
   (quote the cause string from `triage_budget.py`), and never calls `verify_turn`'s
   replay for that turn (spy/assert — a skipped turn is not replayed, and it is never
   PASS, never WARN).
3. The `--json` output carries an additive `triage` section when triage is configured —
   **absent-never-zero** when it is not (the `approval` precedent: absent key, not a
   zero).
4. Shadow mode: configured author, no budget flags ⇒ every turn replayed (verdicts
   identical to no-triage), scores recorded in the `triage` section.
5. `--no-triage` beats a configured `BELAY_TRIAGE_AUTHOR` env (mirror `--no-claim-axis`
   `cli.py:947`).
6. Threshold and top-N each demonstrably skip exactly the named turns end-to-end through
   the CLI with a stub author (deterministic scores).
