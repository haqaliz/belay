**Date:** 2026-07-24 · **Owner:** aliz · **Axis:** A2 · **Capability:** C3 hardening
**Spec:** `docs/planning/replay-relocation-shell/shell-command-string-remap/spec.md`
**Depends on:** aspect 1 (`shell-detect-abstain`) — MERGED on this branch (`command_embeds_in_root_path`,
`EMBEDDED_PATH_UNRELOCATABLE`, the gate ordering, the `run_process` fixture). Baseline: 732 passed.

## Goal

Turn the aspect-1 **abstain** into a faithful **relocation** for the tractable case: a whole-token
in-root path inside a `run_process` `command_line`/`argv`. Such a turn replays against the scratch
and earns a real PASS/FAIL. Anything not provably a clean whole-token path keeps abstaining
(`EMBEDDED_PATH_UNRELOCATABLE`). No content is ever corrupted. **B fails safe: any doubt → abstain,
never a false verdict.**

## Phase 0 — Feasibility spike FIRST (byte-span recovery), timeboxed

Before building, resolve the PRD's flagged crux: can we replace a whole-token path **in place**
without re-quoting drift or prefix collisions (`/root/x` vs `/root/xy`)?

- **Decision rule for the spike:** implement `relocate_command_line(cmd, from_root, to_root) ->
  (new_cmd, outcome)` where `outcome ∈ {RELOCATED, ABSTAIN}`, using this conservative algorithm:
  1. `shlex.split(cmd, posix=True)`; if it raises → **ABSTAIN**.
  2. Classify each token: whole-value `is_under(tok, root)` → *relocatable*; else `normpath(root)
     in tok` → *embedded residue*; else *inert*.
  3. If any **embedded residue** → **ABSTAIN** (can't safely rewrite a path fused into a token).
  4. Else for each distinct relocatable token, rewrite its occurrences in the ORIGINAL string with
     a **boundary-anchored** regex `(?<![\w/-])<re.escape(tok)>(?![\w/-])` → scratch-remapped value.
     If the match count ≠ the lexer's occurrence count for that token (ambiguous quoting/escaping)
     → **ABSTAIN**. Replace **longest token first** to defeat prefix collisions.
  5. Return `(new_cmd, RELOCATED)`.
- **If the spike shows step 4 is not reliably safe** (quoting cases it can't disambiguate), fall
  back to the PRD-sanctioned reduced scope: **relocate only the whole-`argv`-element case (easy,
  no string surgery), and ABSTAIN every `command_line` string.** Still strictly better than aspect 1
  for `argv`-shaped agents, and 100% honest. Record the decision at the top of this file.
- Spike output: a handful of unit tests in `tests/test_replay_relocate.py` exercising the tricky
  strings (quoted path, prefix-collision pair, escaped space, path in a `--flag=` → abstain) that
  encode whichever scope survives.

## Edge Cases & Error Handling (verdict for each)
| Case | Verdict |
|---|---|
| Whole-token in-root path in `command_line`/`argv` | **relocate** → real PASS/FAIL |
| Path embedded in a token (`--file=/root/x`, prefix-collision ambiguity, un-lexable) | **UNVERIFIED** `EMBEDDED_PATH_UNRELOCATABLE` |
| Whole-`argv`-element in-root path | already relocated by the existing whole-value rule (confirm) |
| `command_line` carrying root as inert data | preserved if relocatable elsewhere, else abstain — never corrupted |
| cwd-relative shell turn | unchanged |

## Determinism / Environment
- No new dependencies (`shlex`, `re` are stdlib). Pure functions; darwin-gate only for the real
  Seatbelt e2e. No clock/network/random.
