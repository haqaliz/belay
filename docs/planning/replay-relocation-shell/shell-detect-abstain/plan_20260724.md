## Goal of this aspect

Close the **silent miss**: a turn whose `arguments` embed an in-root absolute path *inside* a
string value (a shell `command_line`, an `argv` element) is today undetected → replayed against
the original workspace → contaminated verdict. After this aspect such a turn is **detected and
honestly UNVERIFIED** with a named cause, decided **before any restore or spawn**. Actual
relocation of the command string is aspect 2; until it lands, every embedded-path turn abstains.

## ⚠️ As-built amendment (2026-07-24, `1f44cf2`)

Phase 1 below describes a **content-shaped "substring anywhere"** detector
(`arguments_hold_embedded_root`). That was built (`0470499`) and **reverted**: it over-fired on
inert `new_content` fields and regressed the shipped filesystem content-boundary case. The detector
was narrowed to **field-shaped** — `command_embeds_in_root_path(arguments, root)` inspects only the
executed-command fields `command_line` (string) and `argv` (elements embedding a non-whole-value
path); inert content and whole-value paths are not flagged (the latter are already relocated by
`remap_arguments`). Read Phase 1's detector semantics as *"fire on `command_line`/`argv` embedded
paths only."* Everything else in this plan (the `EMBEDDED_PATH_UNRELOCATABLE` cause, the gate
ordering, the report bucket, the fixture) stands as written.

## Naming decision (finalizes the spec's working name)

The spec used the working name `SHELL_COMMAND_UNRELOCATABLE`. Because we adopted the
**server-agnostic** content-shaped detector (PRD Gap 2 resolution), the cause is not shell-specific
— it fires for any embedded in-root path. **Final name: `EMBEDDED_PATH_UNRELOCATABLE`.** Aspect 2
reuses this same cause for the residue it cannot prove safe to relocate.

## Assumptions

- The manifest records `source_root` (shipped in `replay-absolute-path-fidelity`); the mint always
  has a root. The **rootless** embedded case (no `source_root`) is out of scope — without a root
  string there is nothing to substring-match; whole-value rootless abs args already trip
  `ROOTLESS_RELOCATION`. Noted, not handled.
- `_relocation_decision` (`src/belay/replay/engine.py:290-324`) is the single gate; it already
  receives `arguments` and `argv`. No new plumbing to reach it.
- Detection keys on the **concrete recorded root string**: `source_root` appears as a substring of
  a string arg that is **not** itself whole-value `is_under` the root. This is specific (a real
  mkdtemp/workspace path, not a generic `/`) and server-agnostic.

## Implementation Phases (strict TDD: RED → GREEN → REFACTOR)

Phases 1 and 4 are **independent** (detector logic vs the fixture) and can be owned by two
parallel agents; phases 2–3 depend on phase 1.

### Phase 1 — The content-shaped embedded-path detector (pure)

- **Goal:** a pure predicate that recognizes an in-root path embedded as a substring of a
  non-whole-value string argument.
- **Prerequisites:** none.
- **RED — write first** in `tests/test_replay_relocate.py`:
  - `arguments_hold_embedded_root({"command_line": "python /root/w/x.py"}, "/root/w")` → **True**.
  - whole-value `{"path": "/root/w/x"}` → **False** (that is `is_under`'s job, handled elsewhere).
  - out-of-root embedded `{"command_line": "python /other/x.py"}` → **False**.
  - a non-path mention that is not the root substring (`{"cmd": "echo hi"}`) → **False**.
  - nested (`{"a": [{"command_line": "cd /root/w && pytest"}]}`) → **True** (recurses dict/list).
  - the root appearing in a `content`/`newText` field as a substring **still** counts as embedded
    here (True) — because at *detection* time we cannot tell content from a command; the
    conservative floor abstains. (Aspect 2 narrows this via tokenization; aspect 1 must not
    under-detect.) Add an explicit test asserting True for `{"newText": "path is /root/w/x"}`.
- **GREEN — implement** in `src/belay/replay/relocate.py`:
  - `arguments_hold_embedded_root(obj, root) -> bool`: recurse dict/list; for a `str` leaf return
    `True` iff `root` (normalized via the module's normpath convention) is a substring of the
    string **and not** `is_under(leaf, root)` (i.e. embedded, not whole-value). Reuse `is_under`.
  - Add to `__all__`.
  - Keep it pure, no I/O — consistent with the module contract (`relocate.py:9-12`).
- **Validation:** `uv run pytest tests/test_replay_relocate.py -q`.
- **Commit:** `feat(replay): a content-shaped detector for in-root paths embedded in arguments`

### Phase 2 — New cause + gate routes embedded → abstain

- **Goal:** `_relocation_decision` returns the honest abstain for an embedded-path turn, **before**
  the whole-value relocate path, and without misfiring `UNROOTABLE_SERVER_COMMAND`.
- **Prerequisites:** Phase 1.
- **RED — write first** in `tests/test_replay_relocation_wiring.py`:
  - `_relocation_decision("/root/w", {"command_line": "python /root/w/x.py"}, ["node", "srv.js"])`
    → `(None, EMBEDDED_PATH_UNRELOCATABLE)`. **Asserts no UNROOTABLE misfire** even though the argv
    has no in-root token (the shell server is root-less by launch).
  - a whole-value-only turn `_relocation_decision("/root/w", {"path": "/root/w/x"}, ["srv", "/root/w"])`
    still returns `("/root/w", None)` — **regression: existing relocation unaffected**.
  - a turn with **both** a whole-value path and an embedded path → `(None, EMBEDDED_PATH_UNRELOCATABLE)`
    (conservative: never partially relocate).
  - a cwd-relative turn (no in-root anything) → `(None, None)` unchanged.
- **GREEN — implement** in `src/belay/replay/engine.py`:
  - Add `EMBEDDED_PATH_UNRELOCATABLE` as a sibling constant near `:101-114`, with a docstring in
    the style of `ROOTLESS_RELOCATION`/`UNROOTABLE_SERVER_COMMAND`, and add it to `__all__`
    (`:574-578`). Message must start with a **stable prefix** for the report bucket, e.g.
    `"an in-root path is embedded in an argument value; cannot safely relocate"`.
  - In `_relocation_decision`, inside the `source_root is not None` branch, **first**:
    `if arguments_hold_embedded_root(arguments, source_root): return None, EMBEDDED_PATH_UNRELOCATABLE`
    — placed above the `turn_needs_relocation` block so embedded turns never reach whole-value
    relocation. Import the new predicate.
- **Validation:** `uv run pytest tests/test_replay_relocation_wiring.py tests/test_replay_relocate.py -q`.
- **Commit:** `feat(replay): abstain (EMBEDDED_PATH_UNRELOCATABLE) for embedded in-root paths`

## Environment & Determinism

- No new dependencies; stdlib only (consistent with the engine's zero-runtime-deps property).

## Edge Cases & Error Handling (verdict for each)

| Case | Verdict |
|---|---|
| Embedded in-root path in a command string | **UNVERIFIED**, cause `EMBEDDED_PATH_UNRELOCATABLE` (this aspect) |
| Whole-value in-root path only | **relocate** as today (unchanged) |
| Both whole-value and embedded | **UNVERIFIED** (conservative — never partial) |
| Out-of-root embedded path (`/etc/...`) | not detected → replay unchanged (correct; out of scope for relocation) |
| Rootless manifest + embedded path | not detected here (no root string to match); noted out-of-scope — whole-value rootless still trips `ROOTLESS_RELOCATION` |
| cwd-relative shell turn (relative paths + `cwd`) | unchanged; `cwd` whole-value handled by existing rule |

**No silent pass anywhere:** a detected embedded path is always UNVERIFIED-with-cause; an
undetected out-of-root path was never in relocation's scope.
