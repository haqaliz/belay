## 0. Grounding facts (verified against the code, not assumed)

- **Verdict path is reused wholesale.** `verify_turn(records, n, *, server_command, manifest_dir,
  network=None, timeout, replays=3, invariants=()) -> TurnVerdict` (`verify/turn.py:140-150`). A
  non-REPLAYED turn returns `UNVERIFIED` directly (`turn.py:166-174`). **This aspect calls it
  unchanged and never modifies `verify/`.**
- **The correlation key already exists in the trace.** `derive_connection_context(records)`
  (`connection.py:214-285`) emits, per frame that carries W3C context, a record
  `{"kind":"trace_context","seq":<frame seq>,"traceparent":…,("tracestate"/"baggage")}`
  (`connection.py:199-211`). `traceparent` is the raw W3C string `version-traceId-id-flags`.
- **Turn identity** is the positional ordinal `n` over `tool_calls(derive_correlation(records))`
  (`index.py:190-200`); a turn's request frame has a `seq`. Join path: `trace_context.seq` →
  request frame → is it the request frame of `tools/call` ordinal `n`? → that `n` is the turn.
- **CLI pattern:** argparse subparsers in `_parser()` (`cli.py:1107-1517`); groups add nested
  actions via `.add_subparsers`; leaves bind `set_defaults(func=_cmd_…)`; handlers lazy-import heavy
  deps (`cli.py:479-483`). Output sink is `_emit` (`cli.py:73`), plain text, no color.
- **Zero-dep + zero-LLM guards:** `tests/test_import_guard.py:84-111` (stdlib+first-party only),
  `tests/test_verify_zero_llm.py:38` (`GUARDED_ROOTS`). Both must stay green with `interop/` added.

### ⚠️ The one thing to pin in RED, from a REAL capture (spec open question)

W3C `traceparent` = `version-traceId-id-flags`. The MCP client stamps it with **its own current
span** at call time, so the OTLP span representing that MCP call has `spanId == traceparent.id` and
`traceId == traceparent.traceId`. **Working hypothesis for the join: `(span.traceId ==
tp.traceId) AND (span.spanId == tp.id)`.** Before writing the correlation test, the agent MUST
generate one real `trace_context` record (run the existing `manual` mint smoke, or synthesize a
frame with a `_meta.traceparent` and pass it through `derive_connection_context`) and confirm the
field the MCP client actually populates. **Do not invent the fixture shape.** If reality differs,
the join predicate changes — everything downstream keys off it.

## 2. Implementation Phases

Each phase is RED → GREEN → REFACTOR, one commit, suite kept green. P1 and P2 are independent
(parallelizable in Phase 6); P3 depends on P1+P2; P4 on P3; P5 is docs-only, last.

### Phase 1 — OTLP/JSON ingest (stdlib parser)
- **Goal:** parse OTLP/JSON spans into a small internal `Span` dataclass with stdlib `json` only.
- **Prereq:** none.
- **Files:** `src/belay/interop/otlp.py` (new), `tests/test_interop_correlate.py` (new, ingest
  cases), `tests/fixtures/interop/spans_ok.json`, `tests/fixtures/interop/spans_malformed.json`.
- **RED tests:** AC1-ingest (a fixture `ResourceSpans→ScopeSpans→Span` parses to N spans with
  `trace_id`/`span_id`/`name`/`start_time_unix_nano`/`attributes`); **AC8** (malformed → a named
  `OtlpParseError`, never `[]`).
- **Note:** OTLP/JSON encodes ids as **hex strings** in the JSON exporter (bytes base64 in protobuf
  → hex in JSON). Pin fixtures to the OTLP/JSON exporter shape and record the version in a comment.
- **Validation:** `uv run pytest tests/test_interop_correlate.py -q -k ingest`.
- **Commit:** `interop: stdlib OTLP/JSON span ingest (no SDK)`

### Phase 2 — trace_context → turn index + the join
- **Goal:** build `{ (traceId, id) → turn_ordinal_n }` from a trace's `trace_context` records, and a
  join that maps a span to 0, 1, or >1 turns.
- **Prereq:** none (reads a trace via existing `read_trace`/`derive_connection_context`).
- **Files:** `src/belay/interop/correlate.py` (new), same test module.
- **RED tests:** **AC1** (span whose `(traceId,id)` matches a turn's captured traceparent →
  that turn's `n`); **AC4** (span matching >1 turn, or a `traceparent` sitting on a
  **non-`tools/call`** frame → an `Ambiguous`/`Unmatched` sentinel, **never** a picked turn).
- **Determinism:** the index is built by sorted iteration over frames; no clock, no ordering
  ambiguity.
- **Validation:** `uv run pytest tests/test_interop_correlate.py -q -k correlate`.
- **Commit:** `interop: deterministic span↔turn join on captured W3C trace context`

### Phase 3 — attach verdict + the UNVERIFIED-never-PASS paths
- **Goal:** for a uniquely-matched, verifiable turn, call `verify_turn` and attach its `TurnVerdict`;
  for every uncovered case, emit `UNVERIFIED` with a named cause.
- **Prereq:** P1, P2.
- **Files:** `src/belay/interop/attach.py` (new; a `CorrelatedSpan` result type carrying
  span-id, matched `n` or None, `TurnVerdict`, `cause`), same test module.
- **RED tests:** **AC5** (matched+verifiable → the *exact* `TurnVerdict` `verify_turn` returns —
  assert equality with a direct `verify_turn` call on the same fixture); **AC2** (no match →
  `UNVERIFIED`, cause `no-matching-mcp-turn`, asserted **≠ PASS**); **AC3** (match to a turn whose
  pre-state is unrestorable → `UNVERIFIED`, cause `unrestorable-pre-state`); **AC4-attach**
  (ambiguous → `UNVERIFIED`, cause `ambiguous-correlation`, no `verify_turn` call made).
- **Key rule (R5):** the uncovered statuses are produced by the existing `reduce` (empty→UNVERIFIED,
  `verdict.py:80-82`) — do **not** hand-construct a PASS anywhere. A test asserts no code path in
  `interop/` can yield `Status.PASS` for an uncovered span (mirror the spirit of
  `test_verdict.py`).
- **Validation:** `uv run pytest tests/test_interop_correlate.py -q -k attach`.
- **Commit:** `interop: attach the replayed verdict; uncovered→UNVERIFIED, never PASS`

### Phase 4 — report + `belay interop correlate` CLI + `--json`
- **Goal:** the correlation-rate report and the subcommand.
- **Prereq:** P3.
- **Files:** `src/belay/interop/report.py` (new), `src/belay/cli.py` (add `interop` group +

- **CLI shape:** `belay interop correlate <otel-spans.json> <trace-dir-or-file>

- **RED tests:** **AC6** (report prints `matched/total` **with denominator** + uncorrelated bucket

  matched turn `n` → verdict status + rate summary); exit code mirrors `_worst` so an all-UNVERIFIED
  correlation exits non-zero.
- **Validation:** `uv run pytest tests/test_interop_correlate.py -q` (whole module green) +
  `uv run belay interop correlate --help`.
- **Commit:** `interop: belay interop correlate — rate report + --json`

## 4. Testing Strategy

- **Lift the ACs from the spec** (`./spec.md` AC1-AC10) — they *are* the C9 acceptance
  (`CAPABILITY_ROADMAP.md:479-483`) plus the ambiguity/R5 hardening. Written first, per phase above.
- **Fixtures, no network, deterministic.** Build the trace fixture from a real captured
  `trace_context` shape (see §0 ⚠️); build OTLP/JSON fixtures pinned to the OTLP JSON exporter
  format. No clock/random/network anywhere.
- **The load-bearing honesty tests:** AC2/AC3/AC4 (uncovered/ambiguous → UNVERIFIED, never PASS) and
  AC5 (attached verdict is byte-identical to the standalone `verify` path). These are the ones that
  keep C9 from over-claiming (R5) — never weaken them.
- **Guards:** AC9 keeps `test_import_guard` (zero-dep) and `test_verify_zero_llm` (zero-LLM, now
  covering `interop/`) green.
- Commands: `uv run pytest tests/test_interop_correlate.py -q` per phase; `uv run pytest -q` before
  each commit.

## 5. Environment & Determinism

- No env vars, no external services, no new tools. `uv sync` already works on the branch.
- Determinism requirement: correlation is a pure function of (trace bytes, spans JSON). A test whose
  result depends on iteration order, clock, or a live server is a plan bug — the only re-execution is
  `verify_turn`, which is itself deterministic against restored pre-state.

## 6. Edge Cases & Error Handling → verdict/outcome

| Case | Outcome |
|------|---------|
| Span with no matching turn | `UNVERIFIED`, cause `no-matching-mcp-turn` (never PASS) |
| Span matches >1 turn / traceparent on non-`tools/call` frame / duplicate span-id | `UNVERIFIED`, cause `ambiguous-correlation`; no attach |
| Matched turn, pre-state unrestorable | `UNVERIFIED`, cause `unrestorable-pre-state` (from `verify_turn`) |
| Matched turn, no `--server` given | `UNVERIFIED` (not replayed); `--help` states this |
| Malformed OTLP/JSON | `OtlpParseError` (named), non-zero exit; never empty success |
| Trace has zero `trace_context` records (client didn't propagate) | correlation rate `0/total`, all `no-matching-mcp-turn`; reported honestly, not an error |
