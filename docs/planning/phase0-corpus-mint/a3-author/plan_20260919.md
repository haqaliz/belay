## 0. Placement decision (resolved before planning, not during)

The reference author goes in **`src/belay/verify/`**, not `src/belay/authoring/`.

`src/belay/authoring/__init__.py` states its own boundary: *"Invariant authoring: a model
writes A1 policy… **Nothing in this package is in the verdict path.** The author proposes
policy; the control replay calibrates it; the shipped A1 machinery decides."*

**A3 IS in the verdict path** — a claim FAIL downgrades a turn (`verdict.reduce`, A3 may
downgrade but never promote). So placing a claim author in `authoring/` would falsify that
package's stated invariant. It belongs beside the protocol it implements: `claims.py`
(evaluator) and `author.py` (`SubprocessAuthor`, `author_from_env`).

- **Module:** `src/belay/verify/reference_claim_author.py`
- **Runnable as:** `python -m belay.verify.reference_claim_author --model <full-id>`
- **Wired by:** `BELAY_CLAIM_AUTHOR="python -m belay.verify.reference_claim_author --model claude-opus-5"`

⚠️ **Phase 1 must confirm the zero-LLM guard tolerates this.**
`tests/test_verify_zero_llm.py:26-32, 155-165` AST-scans `src/belay/verify/` asserting no
inference-SDK import. The new module is stdlib-only (`subprocess`, `json`, `os`, `argparse`,
`sys`) so it should pass unchanged — but `invariant-authoring` needed *"two deliberate
review-approved guard amendments (producer set + SCAN_AREA)"*, so **verify, do not assume**.
If the guard needs amending, that is a **review-approved decision recorded in the plan**,
never a silent edit.

## 2. The contract being implemented

Consumed by `SubprocessAuthor.author_check` (`src/belay/verify/author.py:76-119`).

**stdin** (built by Belay, `sort_keys=True`):
```json
{"claim": "<text>", "classification": "VERIFICATION",
 "turns": [{"tool": "<name>", "seq": <int>}],
 "final_state_files": ["<relative path>"]}
```

**stdout** — exactly one JSON object:
```json
{"source": "<human-readable check source>", "argv": ["<executable>", "<arg>"]}
```
or `{"error": "<why>"}` → abstention.

Parsed fail-closed by `_parse_check` (`author.py:122-143`): bad JSON, non-object,
`"error"` present, non-`str` source, non-`list` argv, or any non-`str` token → `None`.
`SubprocessAuthor` additionally returns `None` on non-zero exit, timeout
(`AUTHOR_TIMEOUT = 60.0`) or launch failure, and truncates stdout at `_MAX_OUTPUT`
(1 MiB). **Every failure is an abstention → `NO_CHECK_AUTHOR`. Never a crash.**

**Consequence for this module:** it must print exactly one JSON object on stdout and
nothing else. Diagnostics go to **stderr**. A stray `print()` to stdout breaks the parse
and silently disables A3.

## 5. Testing strategy

- **Unit, offline, deterministic** — every test in Phases 1–4. No network, no clock, no
  real model. The model call sits behind the injected `runner=` seam.
- **Live** — Phase 5 only, `manual`-marked, owner-run, never CI.
- **Guards** — the six in Phase 4 assert this aspect changed nothing it must not.
- **Commands:** `uv run pytest <path> -q`; full suite `uv run pytest`.

**Determinism:** no test may depend on clock, network or ambient env. The env-scrub tests
must **set** the three `ANTHROPIC_*` vars explicitly rather than relying on the box's
state — `ANTHROPIC_BASE_URL` happens to be set here, and a test that passes only because
of that is not a test.

## 6. Edge cases & the UNVERIFIED path

Every failure is an **abstention with a named cause** — never a crash, never a fabricated
verdict, never PASS.

| Condition | Result | Cause |
|---|---|---|
| Author unset/blank/un-lexable | axis ABSENT | (coverage note, not UNVERIFIED) |
| Author raises / non-zero / timeout / unparseable | UNVERIFIED | `NO_CHECK_AUTHOR` |
| Author returns `{"error":…}` | UNVERIFIED | `NO_CHECK_AUTHOR` |
| Check cannot launch under `contained()` deny-all | UNVERIFIED | `CHECK_DID_NOT_EXECUTE` (runner error verbatim) |
| Check exits 0 | **silence (D3)** — never PASS | — |
| Check exits non-zero | **FAIL** | the A3 verdict |
| No claim record in trace | UNVERIFIED | `NO_CLAIM_RECORDED` |
| Claim not `VERIFICATION` | UNVERIFIED | `CLAIM_UNCLASSIFIABLE` |
| Final turn unreplayable | UNVERIFIED | `FINAL_STATE_UNOBSERVABLE` |

All satisfy **M4** (*column filled with a verdict or a named cause, never "claim
unrecorded"*).
