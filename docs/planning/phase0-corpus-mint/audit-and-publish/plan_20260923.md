## Context (read first)

## Phase 1 — the evidence pack (agents, from committed ledgers + outputs)

**Files** in `docs/planning/phase0-corpus-mint/audit-and-publish/`:
- `FLAGS.md` — every flagged turn + the trajectory table, from the committed stage
  ledgers (`$HOLDER/runs/cm-run2-stage{1,2}.json` — but the committed source of truth
  is the verbatim `.out` files in `mint-run/`; re-render via `uv run belay phase0
  report`/`phase0 combine` where the ledger is committed). Every line attributable.
- `AUDIT.md` — the owner's adjudication surface: every flag and every trajectory FAIL
  listed with its evidence (tool, turn, cause, sub-verdicts), root-cause keys,
  independence off `(instance, tool)`. **Header restates S-1 and the evidence-grade
  split** (execution vs human adjudication, never merged). No TP/FP/FN words applied
  by the preparer.
- `HAND_REPLAY.md` — one flagged case (or one trajectory FAIL) replayed end-to-end
  through `belay corpus run` if any FAIL exists; if none exists, the file says so
  plainly (the honest case is the more important one to write well).
- `REPRODUCIBILITY.md` — a clean-checkout re-render of the ledgers is byte-identical
  to the committed outputs (mismatch → STOP); the `not-a-gate-run` sentence; the
  engine-version delta (run 1: 0.33.0 → run 2: v0.37.0) and the NOT_COVERED boundary
  statement (UNVERIFIED rates across runs NOT comparable); the pre-registered-branch
  note if the run stopped early.
- The decision line the owner signs: continue / stop / re-scope — left unsigned.

**Validation:** A1–A4 from the spec: first-paragraph honesty in all three places;
every ledger line re-derivable; zero flags dropped, zero judged; version delta +
boundary stated wherever a rate appears.
**Commit:** `docs(audit-and-publish): the evidence pack for the owner's adjudication`

## Phase 2 — the record (agents)

- `CLAUDE.md` — the top block (the newest block at the top of the file).

**Validation:** A5–A6: no number moves; `precision`/`recall` read `n/a` wherever the
corpus is scored; the three honesty paragraphs agree.
**Commit:** `docs(audit-and-publish): the record — PHASE0_RESULTS, STATUS, CLAUDE, checklist`

## Edge cases

- A run that banked nothing still ships a full pack — the honest case is written with
  the same care; the pre-registered branch's read is stated verbatim.
- AUDIT.md drifting into judgment is the unit's strongest self-discipline risk — the
  S-1 header is mandatory and the file is reviewed at the merge gate.
- Any attempt to re-derive a published number is out of scope and must be flagged.
