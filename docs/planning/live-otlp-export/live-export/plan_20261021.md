# Plan — live OTLP/JSON exporter (issue #54)

Strict TDD. Branch `feat/54/aliz`.

## Task 1 — transport (RED → GREEN)

`src/belay/interop/export.py`: `post_document(url, document, headers=()) -> None`.

- stdlib `urllib.request.Request` + `urlopen`, POST, `Content-Type: application/json`,
  timeout `REQUEST_TIMEOUT = 10.0`.
- Any `OSError`, `HTTPError`, `ValueError` propagates as `ExportError(OSError)` with the URL
  and reason, never swallowed.
- Module docstring: the builder stays pure; the transport is opt-in and the only place that
  touches the network.

Tests `tests/test_interop_export.py` (local `ThreadingHTTPServer`, no external network):
- body bytes equal `dumps(document)`; content-type header; 200 returns;
- headers arrive verbatim; 500 raises `ExportError` naming the URL/status; connection
  refused raises `ExportError`; no request body mutation.

## Task 2 — CLI wiring (RED → GREEN)

`src/belay/cli.py`:
- `--otlp-endpoint URL`, `--otlp-header NAME=VALUE` (append), both before `--server`;
- `--otlp-endpoint` + `--out` → exit 2 (`belay: --otlp-endpoint and --out are mutually
  exclusive`);
- malformed header → exit 2 named;
- serialize once with `dumps`; endpoint → `post_document`; out → write; else stdout;
- transport failure → exit 1 `belay: cannot export to {url}: {exc}`;
- stderr summary: `export` is the URL when posting; help/docs updated.

Tests `tests/test_interop_export_cli.py`:
- endpoint 200 → rc 0, stdout empty, stderr summary names the URL;
- 500 and connection-refused → rc 1 named;
- both flags → rc 2; malformed header → rc 2;
- the posted body parses with `parse_otlp` and keeps the coverage attribute.
